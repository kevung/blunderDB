Keyboard shortcuts

Database

Shortcut

Action

CTRL-N

Create a new database.

CTRL-O

Open an existing database.

CTRL-SHIFT-I

Merge a database into this one.

CTRL-SHIFT-S

Export the database.

CTRL-Q

Close blunderDB.

CTRL-M

Edit database metadata.

Position

Shortcut

Action

CTRL-I

Import one or more positions/matches from file (xg, xgp, sgf, mat, txt, bgf).

CTRL-SHIFT-F

Recursively import a folder of match/position files.

CTRL-C

Copy a position to the clipboard.

CTRL-X

Copy board image to clipboard (PNG).

CTRL-X CTRL-X

Copy board + analysis image to clipboard (PNG).

CTRL-V

Paste a position from the clipboard (automatic format detection).

CTRL-S

Save a position.

CTRL-U

Update a position.

Del

Delete the current position (confirmation required).

BACKSPACE

Reset board, cube, score, and dice.

CTRL-G

Show the position metadata.

Navigation

Shortcut

Action

CTRL-R

Reload all the positions from the database.

PageUp, h

First position / Previous game (match navigation).

LEFT, k

Previous position.

RIGHT, j

Next position.

UP, k

Previous move (when a move is selected in the analysis).

DOWN, j

Next move (when a move is selected in the analysis).

PageDown, l

Last position / Next game (match navigation).

r

Load a random position.

Display

Shortcut

Action

CTRL-LEFT

Board orientation to the left.

CTRL-RIGHT

Board orientation to the right.

p

Show/hide pipcount.

Actions

Shortcut

Action

TAB

Open the search panel (position editor).

SPACE

Open the command line.

Tools

Shortcut

Action

CTRL-L

Show/hide the analysis.

CTRL-P

Show/hide the comments.

CTRL-K

Show/hide the Anki panel (spaced repetition).

CTRL-F

Show/hide the search panel.

CTRL-Tab

Show/hide the match panel.

CTRL-B

Show/hide the collections panel.

CTRL-Y

Show/hide the tournaments panel.

CTRL-D

Show/hide the Stats panel.

CTRL-E

Show/hide the Eval panel.

?

Show/hide the help.

View Tabs

Shortcut

Action

CTRL-T

Create a new view (a copy of the current view).

CTRL-W

Close the current view.

CTRL-PageUp, SHIFT-J

Previous view.

CTRL-PageDown, SHIFT-K

Next view.

CTRL-1 … CTRL-9

Go directly to the n-th view.

Double-click the tab

Rename the view.

Command Line

Shortcut

Action

UP

Browse command history up.

DOWN

Browse command history down.

Search History

Shortcut

Action

Click

Select/deselect a search (show position).

Double-click

Execute the search.

Filter Library

Shortcut

Action

Click

Select/deselect a filter (show position).

Double-click

Execute the filter search.

Analysis Panel

Shortcut

Action

Click

Select/deselect a move (show/hide arrows).

UP, k

Select previous move (when a move is selected).

DOWN, j

Select next move (when a move is selected).

d

Toggle between checker and cube analysis (match navigation only).

Esc

Deselect move. If no move selected, close the panel.

Eval Panel

Shortcut

Action

Click

Select/deselect a move (show/hide arrows).

UP, k

Select previous move (when a move is selected).

DOWN, j

Select next move (when a move is selected).

Esc

Deselect move.

Match Panel

Shortcut

Action

Click

Select a match.

Double-click

Navigate the match.

UP, k

Select previous match.

DOWN, j

Select next match.

ENTER

Load the selected match.

Del

Delete the selected match.

Esc

Deselect/close the panel.

Anki panel (spaced repetition)

Shortcut

Action

SPACE, Click

Show the answer (the recorded analysis of the position).

1

Rate: Again (failed, review soon).

2

Rate: Hard.

3

Rate: Good.

4

Rate: Easy.

p

Show/hide the pip count (same as the general shortcut, available during review).

Esc

Stop the review and return to the deck list (can resume later).

Tournament Panel

Shortcut

Action

Click, Double-click

Select a tournament (show its detail).

UP, k

Select previous tournament.

DOWN, j

Select next tournament.

Double-click (on a match of the tournament)

Navigate the match.

Esc

Cancel the current edit, otherwise clear the add-match search, otherwise deselect the tournament, otherwise close the panel (one step at a time).

Collection Panel

Shortcut

Action

Click

Add/remove the current position to/from the hovered collection.

Double-click

Open the collection.

Del

Remove the current position (or the checked positions) from the open collection.

Esc

Go back to the collection list, otherwise deselect the collection, otherwise close the panel (one step at a time).

Help Panel

Shortcut

Action

LEFT, h

Previous tab.

RIGHT, l

Next tab.

UP, k

Scroll up.

DOWN, j

Scroll down.

SPACE

Next page.

PageUp

Top of the content.

PageDown

Bottom of the content.

?, CTRL-F, Esc

Close the help.
