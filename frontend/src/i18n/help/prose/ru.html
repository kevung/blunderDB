Введение

blunderDB — это программа для создания баз данных позиций нард. Её главное достоинство — предоставить единое место для накопления позиций, с которыми игрок столкнулся (онлайн, на турнирах), и возможность повторно изучать эти позиции, фильтруя их по различным произвольно комбинируемым фильтрам. blunderDB также можно использовать для создания каталогов эталонных позиций.

Позиции хранятся в базе данных, представленной файлом .db.

Основные действия

Основные действия, доступные в blunderDB:

  • добавление новой позиции,
  • изменение существующей позиции,
  • копирование доски как изображения PNG в буфер обмена (Ctrl+X) или доски вместе с её анализом (Ctrl+X, Ctrl+X),
  • удаление существующей позиции,
  • поиск одной или нескольких позиций,
  • импорт матчей из различных источников (XG, GNUbg, BGBlitz, Jellyfish), включая комментарии из файлов XG,
  • просмотр ходов импортированного матча,
  • организация позиций в коллекции,
  • организация матчей в турниры,
  • пакетный анализ, из терминала, позиций без анализа с помощью встроенного анализатора gammonNet (команда analyze в blunderDB).

Пользователь может свободно помечать позиции тегами и снабжать их комментариями.

Описание интерфейса

Интерфейс blunderDB структурирован сверху вниз следующим образом:

  • [вверху] панель инструментов, которая собирает все основные операции, выполняемые над базой данных,
  • [в середине] основная область отображения, которая позволяет отображать или редактировать позиции нард,
  • [внизу] строка состояния, которая включает командную строку и представляет различную информацию о текущей позиции.

Панели можно отобразить для того, чтобы:

  • отображать данные анализа, связанные с текущей позицией (из XG, GNUbg или BGBlitz),
  • отображать, добавлять или изменять комментарии,
  • просматривать импортированные матчи и перемещаться по их ходам (панель Match),
  • управлять коллекциями позиций (панель Collection),
  • изучать позиции с помощью интервальных повторений (панель Anki),
  • управлять турнирами (панель Tournament),
  • отображать статистику результативности (панель Stats),
  • вычислять значения EPC для позиций вывода шашек (панель расчёта),
  • просматривать сохранённые фильтры поиска (панель Filter Library),
  • просматривать историю поиска (панель Search History).

Основная область отображения предоставляет пользователю:

  • доску для отображения или редактирования позиции нард,
  • уровень и владельца cube,
  • pip count каждого игрока,
  • счёт каждого игрока,
  • кости для разыгрывания. Если на костях не отображается значение, положение костей указывает, чей ход, и что позиция является решением о cube.

Строка состояния отображает слева направо:

  • командную строку (нажмите Space, чтобы открыть),
  • информационное сообщение, относящееся к последней выполненной операции,
  • индекс текущей позиции, за которым следует общее число позиций (или информация о ходе/партии при навигации по матчу).

В случае позиций, полученных в результате пользовательского поиска, число позиций, указанное в строке состояния, соответствует числу отфильтрованных позиций.

Просмотр позиций

По умолчанию blunderDB позволяет:

  • прокручивать различные позиции в текущей библиотеке,
  • отображать информацию анализа, связанную с позицией,
  • отображать, добавлять и изменять комментарии к позиции.

Редактирование позиций

Нажатие клавиши Tab открывает панель поиска и позволяет редактировать позицию на доске, чтобы добавить её в базу данных или задать структуру позиции для поиска. Распределение шашек, cube, счёт и ход можно изменять с помощью мыши.

Командная строка

Командная строка, встроенная в строку состояния, позволяет выполнять все возможности blunderDB: операции с базой данных, навигацию по позициям, отображение анализа и комментариев, поиск позиций с фильтрами... Освоившись с интерфейсом, рекомендуется постепенно переходить к использованию командной строки, которая обеспечивает мощную и удобную работу с blunderDB, особенно для функций поиска позиций.

Чтобы открыть командную строку, нажмите клавишу Space. В строке состояния появится приглашение. Введите команду и нажмите Enter для выполнения. Нажмите Escape для отмены.

blunderDB выполняет запросы, отправленные пользователем, при условии что они корректны, и немедленно изменяет состояние базы данных при необходимости. Никаких явных действий сохранения от пользователя не требуется.

Чтобы уточнить поиск среди ранее отфильтрованных позиций, используйте команду ss, за которой следуют фильтры (например, ss nc). Это ограничивает поиск только текущими отображаемыми позициями, позволяя постепенно сужать результаты. Панель поиска (Ctrl+F) также предлагает флажок «Search in current results» для той же функции.

Панель Eval

Панель Eval оценивает любую позицию на доске: вероятности выигрыша, гэммона и бэкгэммона, эквити, упорядоченные варианты ходов и то единственное решение, которого требует позиция — сыграть ход или удвоить. Расчёт выполняет встроенный gammonNet: ни eXtreme Gammon, ни GNU Backgammon не нужны.

Чтобы открыть её, нажмите Ctrl+E, щёлкните вкладку Eval нижней панели или введите epc в командной строке. Доска открывается в стандартной расстановке для выбрасывания (15 шашек), если только туда не была отправлена позиция из базы. Шашки свободно добавляются и убираются мышью; оценка следует за каждым изменением.

На позиции выбрасывания панель специализируется: вторая таблица, по игрокам, содержит EPC (Effective Pip Count), вычисленный по односторонней 6-пунктовой базе выбрасывания GNUbg —

  • EPC: среднее число пипов, нужное чтобы вывести все шашки,
  • Pip Count: сырой пип-каунт,
  • Wastage: разница между EPC и пип-каунтом,
  • Avg Rolls: среднее число бросков до вывода всех шашек,
  • Std Dev: стандартное отклонение этого числа бросков.

Когда у обоих игроков есть шашки в доме, раздел сравнения показывает разницу EPC и пип-каунта.

В чистой гонке ещё одна таблица показывает вероятности выигрыша обоих игроков и, если позиция покрыта двусторонней базой (встроенной до 6 шашек на игрока, загружаемой расширенной до 11 через вкладку Bearoff в настройках), точные money-эквити и лучшее решение по кубу. За пределами этой области вероятность выигрыша оценивается приблизительно (значок «оценка» с погрешностью) и решение не показывается. Игрок на ходу меняется щелчком по прямоугольнику выхода/счёта игрока, положение куба — щелчком по кубу на доске.

Флажок Вызов скрывает результаты при каждом изменении позиции; щёлкните область, чтобы раскрыть её — удобно, чтобы потренироваться оценивать эквити, EPC или решение по кубу перед проверкой.

Чтобы закрыть панель Eval, нажмите Ctrl+E ещё раз или перейдите на другую вкладку.

Навигация по матчу

blunderDB позволяет просматривать ходы импортированных матчей. Откройте панель Match с помощью Ctrl+Tab и дважды щёлкните матч (или нажмите Enter), чтобы загрузить его позиции.

При навигации по матчу последняя посещённая позиция автоматически сохраняется и восстанавливается. Используйте клавиши Left/Right для перемещения между позициями и PageUp/PageDown для перехода между партиями.

Панель анализа (Ctrl+L) показывает анализ для каждого хода, с выделением сыгранного хода. Нажмите d, чтобы переключаться между анализом хода и cube.

Коллекции

Коллекции позволяют организовывать позиции в пользовательские группы. Откройте панель Collection с помощью Ctrl+B, затем дважды щёлкните коллекцию, чтобы просмотреть её позиции. Коллекции и позиции внутри них можно переупорядочивать перетаскиванием.

Anki (интервальные повторения)

Панель Anki (Ctrl+K) обеспечивает интервальные повторения для изучения позиций нард с помощью алгоритма FSRS.

Создание колод: Щёлкните New Deck, чтобы создать колоду из коллекции или из текущих результатов поиска. Колоды на основе поиска автоматически синхронизируются при активации вкладки Anki.

Повторение: Выберите колоду и щёлкните Study (или дважды щёлкните колоду), чтобы начать повторение карточек к показу. Каждая карточка отображает соответствующую позицию на доске. Оцените своё воспроизведение клавишами 1 (Again), 2 (Hard), 3 (Good) или 4 (Easy). Нажмите Esc, чтобы остановиться и вернуться к списку колод.

Ограничение сессии: В настройках колоды можно ограничить сессию числом карточек. Тогда сессия завершается с соответствующим сообщением, а свободная тренировка остаётся доступной и не влияет на расписание. Предел 0 не выдаёт ни одной карточки — это не то же самое, что отсутствие предела.

Удержание: Целевое удержание — ваш выбор в компромиссе между нагрузкой и качеством. Рядом настройки показывают измеренное удержание по вашим повторениям: это сведения, а не управление. Изменение цели не имеет обратной силы: каждая карточка перейдёт на новый ритм при следующем повторении.

Показ ответа: Карточка задаёт вопрос; подумайте, затем нажмите Пробел (или щёлкните по скрытой области), чтобы открыть сохранённый анализ позиции. Он появляется под кнопками оценки, которые остаются под рукой. Открывать ответ для оценки не обязательно, и он снова скрывается на следующей карточке — но не при простом переключении вкладки.

Остановка/Возобновление: Вы можете остановить сессию повторения в любой момент, нажав Esc. Кнопка изменится на Resume, показывая ваш прогресс. Щёлкните её, чтобы продолжить с того места, где вы остановились.

Управление колодами: Используйте кнопки действий для переименования, синхронизации, сброса или удаления колод. Параметры FSRS (целевое удержание, максимальный интервал, fuzz) можно настроить для каждой колоды в Настройках (значок шестерёнки).

Турниры

Турниры позволяют группировать матчи по событию. Откройте панель Tournament с помощью Ctrl+Y, чтобы управлять турнирами и назначать им матчи.

Статистика

Панель Stats (Ctrl+D) отображает статистику результативности (PR и стоимость в MWC), вычисленную по всем импортированным позициям. Используйте панель фильтров, чтобы ограничить анализ по игроку, турниру, диапазону дат, типу решения или длине матча. Щёлкните любой показатель, чтобы детализировать соответствующие позиции. Вкладка «Игроки» показывает по каждому игроку число матчей, счёт, решения, PR (шашки и куб), Snowie, бландеры и удачу, измеренную по известным броскам.

Отметка и защищённый экспорт

При экспорте (export_db или диалог «Экспорт») можно свободно включить две независимые защиты — одну, другую или обе сразу:

  • Отметка: отмечает экспортированный файл его происхождением (кто его создал, необязательная заметка). Отметка подписана вашей идентичностью автора: её нельзя изменить или подделать от чужого имени — но она не является неудаляемой и не мешает копированию.
  • Пароль: помещает экспорт в зашифрованный контейнер .dbx. Он защищает файл при передаче, а не саму базу — тот, кому вы дали пароль, сможет его открыть — а происхождение читается и без пароля.

Ваша идентичность автора — ключ, которым подписываются ваши отметки, — создаётся автоматически при первом экспорте, отмеченном происхождением. Просмотрите, экспортируйте или пересоздайте её на вкладке Идентичность автора настроек.
