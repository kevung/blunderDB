# Third-party notices

blunderDB is released under the MIT License (see `LICENSE`). Its binaries —
the desktop application, the command-line interface and the headless `serve`
daemon are one executable — embed data, models, libraries and fonts written by
other people. This file lists them, with the licence each one is used under
and where it lives in the source tree, so that every copy of blunderDB carries
the notices those licences require.

Every licence below was read from the upstream `LICENSE` file or the font's
name table, not inferred from a repository name. Packages install this file
under `/usr/share/doc/blunderdb/` (`.deb`, `.rpm`, Docker image),
`/usr/share/licenses/blunderdb-bin/` (Arch) or `/app/share/doc/blunderdb/`
(Flatpak); the Linux tarball ships it next to `INSTALL.txt`.

These are compiled into every binary (`//go:embed`).

| **`strehl-prune-32`** pruning network | gammonNet, distilled from the Strehl network above | MIT | The small network that ranks candidate moves before the full evaluation. | `pkg/blunderdb/engine/gammonnet/strehl-prune-32_*.bin`, from [kevung/gammonNet](https://github.com/kevung/gammonNet) (`models/prune_32.provenance.json`) |

| **Kazaross-XG2 match equity table** | Neil Kazaross | Work of Neil Kazaross, used with attribution | The 25×25 pre-Crawford table and the 24 post-Crawford entries, produced by XG rollouts to 9 points, GNU Backgammon Supremo to 15, and extended to 25 by projecting take points. | **Two-sided bearoff database** `gnubg-TS-06-06` (6 points, 6 checkers) | Generated with GNU Backgammon | Same as above | Exact money-game cube verdicts in pure bearoff races (`engine/race`, ADR-0009). | `pkg/blunderdb/engine/race/gnubg_ts0.bd` (6.8 MB); [GNU Backgammon](https://www.gnu.org/software/gnubg/) |

No GNU Backgammon source code is included in blunderDB. GNUbg is also used, at
development time only, as a measurement oracle for the engine's tests; that
never ships.
