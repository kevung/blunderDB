# Third-party notices

blunderDB is released under the MIT License (see `LICENSE`). Its binaries —
the desktop application, the command-line interface and the headless `serve`
daemon are one executable — embed data, models, libraries and fonts written by
other people. This file lists them, with the licence each one is used under
and where it lives in the source tree, so that every copy of blunderDB carries
the notices those licences require.

Every licence below was read from the upstream `LICENSE` file or the font's
name table, not inferred from a repository name. Packages install this file
under `/usr/share/doc/blunderdb/` (`.deb`, `.rpm`, Docker image),
`/usr/share/licenses/blunderdb-bin/` (Arch) or `/app/share/doc/blunderdb/`
(Flatpak); the Linux tarball ships it next to `INSTALL.txt`.

## 1. Embedded data and models

These are compiled into every binary (`//go:embed`).

| Component | Author | Licence | What blunderDB uses | Where |
|---|---|---|---|---|
| **`strehl-prob5-512-512-256-128`** neural network | Alexander Strehl | MIT (notice reproduced in §5) | The evaluation network's weights, unchanged. The network keeps its author's name: neither the search around it nor this port makes it a new network. | `pkg/blunderdb/engine/gammonnet/strehl-prob5-512-512-256-128_*.bin`, from [alexstrehl/backgammon-ai-engine](https://github.com/alexstrehl/backgammon-ai-engine) (commit `b2750df`) |
| **`strehl-prune-32`** pruning network | gammonNet, distilled from the Strehl network above | MIT | The small network that ranks candidate moves before the full evaluation. | `pkg/blunderdb/engine/gammonnet/strehl-prune-32_*.bin`, from [kevung/gammonNet](https://github.com/kevung/gammonNet) (`models/prune_32.provenance.json`) |
| **gammonNet** evaluator | Kévin Unger | MIT (`pkg/blunderdb/engine/gammonnet/LICENSE.gammonNet`) | The search, cube model and match-equity handling around the network, ported from C to Go. The C rules and inference engine the port follows are Alexander Strehl's (`c_engine/bg_engine.c`, `c_inference/nn_eval.c`, MIT). | `pkg/blunderdb/engine/gammonnet/`, from [kevung/gammonNet](https://github.com/kevung/gammonNet) (tag named by `EngineVersion`) |
| **Kazaross-XG2 match equity table** | Neil Kazaross | Work of Neil Kazaross, used with attribution | The 25×25 pre-Crawford table and the 24 post-Crawford entries, produced by XG rollouts to 9 points, GNU Backgammon Supremo to 15, and extended to 25 by projecting take points. Published in Tom Keith's article [The Kazaross-XG2 Match Equity Table](https://bkgm.com/articles/Keith/KazarossXG2MET/index.html); GNU Backgammon distributes it as `met/Kazaross-XG2.xml`. | `pkg/blunderdb/engine/met.go`; `frontend/src/stores/metTable.js` (the `met` command) |
| **Take-point and gammon-value tables** | Dirk Schiemann, *The Theory of Backgammon* | Quoted with attribution | The reference tables shown by the `tp2`, `tp4`, `gv1`, `gv2`, `gv4` commands. | `frontend/src/stores/takePoint*Table.js`, `gammonValue*Table.js` |
| **One-sided bearoff database** `gnubg-OS-06-15` (6 points, 15 checkers) | Generated with GNU Backgammon | Data produced by GNU Backgammon's `makebearoff`; the program is GPL-3, the tables it outputs are not covered by that licence ([GPL FAQ](https://www.gnu.org/licenses/gpl-faq.html#WhatCaseIsOutputGPL)). Credited as generated by GNUbg. | Exact effective pip counts (EPC) and one-sided bearoff distributions. | `pkg/blunderdb/engine/gnubg_os6.bd` (1.4 MB); [GNU Backgammon](https://www.gnu.org/software/gnubg/) |
| **Two-sided bearoff database** `gnubg-TS-06-06` (6 points, 6 checkers) | Generated with GNU Backgammon | Same as above | Exact money-game cube verdicts in pure bearoff races (`engine/race`, ADR-0009). | `pkg/blunderdb/engine/race/gnubg_ts0.bd` (6.8 MB); [GNU Backgammon](https://www.gnu.org/software/gnubg/) |

No GNU Backgammon source code is included in blunderDB. GNUbg is also used, at
development time only, as a measurement oracle for the engine's tests; that
never ships.
