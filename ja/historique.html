バージョン履歴

バージョンは新しいものから古いものへと並べてあり、変更ごとに1つの項目が対応します。各バージョンの末尾には、そのバージョンがもたらしたものを詳しく説明するページへの参照が置かれています。のちのバージョンで取り消された項目には、それを置き換えたバージョンが併記されています。この一覧はソフトウェアの歴史を語るものであり、インストールされているバージョンを説明するものではありません。

更新のあとに

データベーススキーマの移行は、開いたときに自動的に行われ、元に戻せません。移行後のデータベースは blunderDB の以前のバージョンでは読めなくなるため、事前にバックアップを取っておきます（付録: データベーススキーマ）。それ以外は自動では行われません。以下のデータはいずれも遡及しないからです：

  • 古くなったポジションの再解析（0.38.0）。0.38.0 より前に書き込まれた gammonNet の解析は、それ以前のエンジン（以後 gammonNet v1.6.0）によるものです。blunderdb analyze --stale、またはボタン 古くなったポジションを再解析 で書き直されます。インポートされた解析には一切手を加えません。

  • 運を得るには元ファイルを再インポートする（0.33.0）。それ以前にインポートされたマッチは 運 の列にダッシュが入りますが、ダッシュはゼロではありません。運を運ばない形式（BGF、Jellyfish の .mat）が運をもたらすことは決してありません。

  • マークを得るには XG ファイルを再インポートする（0.30.0）。eXtreme Gammon で付けられたマークは、再インポート時にデータベースに反映されます。既存のコメントや分析に影響はありません。

  • gammonNet 分析の穴埋めを実行する（0.34.0）。インターフェースから、blunderdb analyzeで、あるいはサーバーモードで実行します。分析がまったくないポジションを埋めるだけで、インポートされた分析を上書きすることは決してありません。

  • gammonNet の解析の追い込みを再実行する（0.39.0）。移行は、テイクまたはパスについて受け手の判断として計算された gammonNet の評価を消去します。追い込みは、それらをダブル前のダブルした側の判断として書き直します。

0.39.0 (2026-10-10)

  • マッチの動画：ローカルファイルまたは YouTube のリンクをマッチに添付でき、マッチパネルは、調べている判断のロールの1秒前から動画を開きます（行のアイコンまたはvキー）。

  • 盤の横の動画：盤の領域は動画と盤で分け合い、位置が記憶されるハンドルの両側に並びます。⇄ またはハンドルで動画の側を選び、[と]で再生速度を調整します。速度は動画の中央に大きな表示で示されます。

  • トランスクリプションが動画に追従します：動画ペインは各アクションのマーカー（ロールの時刻、アクションの時刻）を置きます。SPACE、SHIFTと矢印、v、SHIFT-Vで再生とマーカーを操作し、セルをクリックすると動画がそのマーカーに移動し、再生中はカーソルが動画に追従します。

  • 各手の所要時間は、マーカーから導かれて棋譜の列に表示されます。行動の時刻がない手には推定の所要時間があり、他と同じように表示されます。

  • 棋譜モードのバーは三つのグループで構成されます。下書き、動画メニュー（ローカルファイル、YouTube リンク、動画を外す）のある入力、そして完了、レジグン、テキストと.matエクスポートを収めた ⋯ メニューです。

  • シアターモード：F11でウィンドウが動画付きの全画面になり、上に小さな盤が浮かび、入力用のキーボードは有効なままです。

  • タブで構成されるマッチのカード：ヘッダーとプレイヤー別の総括の要約は上に残り、その下の棋譜、グラフ、見直し、詳細、情報、統計の各タブはそれぞれ単独でスクロールします。選んだタブは記憶され、グラフはグラフタブの高さを分け合います。

  • マッチの総括：見直すべき判断、運を調整した結果の MWC への換算、ミスのリズム（プレイヤーの所要時間の中央値に照らした、急いだものか熟考したものか）、そして PR と L₇ 損失とそれぞれの区間を示します。blunderdb match --format summaryとルート stats.matchReview でも得られます。

  • 7ポイントマッチに換算した MWC 損失（L₇）は、マッチ一覧、マッチの統計、トーナメント、ダッシュボード、進捗で PR の隣に表示され、blunderdb stats、stats progression、match にも出ます。

  • 各判断の難しさと避けられたミス：トランスクリプションと損失グラフがそれらを示し、マッチのヘッダーはプレイヤーごとに難しさ、超過、比率、避けられたミスの数を示します。

  • 95 % 区間が PR と内訳の各セルに付き、マッチ単位で再標本化されます。

  • トーナメントの総括：トーナメントパネルの総括ボタンは、プレイヤーのトーナメントを普段の水準と比較し、ラウンド別、判断の順位別、プレッシャーのかかるスコア別、リズム別、そしてミスの系統別に内訳を示します。blunderdb stats tournamentとサーバーでも得られます。

  • ダッシュボードの学習プランカードは、ミスの系統を取り戻せる MWC の順に並べ、各系統は学習キュー、クイズ、Anki デッキの元になります。blunderdb stats planはそのコマンドライン版です。

  • 学習の前後と符号付きバイアス：ダッシュボードは、学習した内容がマッチでの損失を減らしたか、またプレイヤーがどちらの方向に誤るかを測ります。blunderdb stats effectと stats biases でも得られます。

  • 基準局面：コレクションパネルの提案…ボタンは、ある範囲（データベース、現在のマッチ、トーナメント、統計のフィルター）で学習すべき局面を提案し、コレクション、Anki デッキ、クイズにできます。blunderdb collection suggestはもう一つの形態です。

  • マッチはごみ箱を経由します：削除したマッチは、番号、インポート日、ゲーム、解析、局面も含めてそのまま復元できます。blunderdb trash delete --kind matchも同じ操作を行います。

  • 指標ページは、各指標の定義、式、限界を示します。ミス、PR、MWC 損失、難しさ、区間、総括、学習プラン、基準局面、前後比較、バイアスです。

  • 手の入力はどこでも盤上で同じ方法です：デュエル、トレーニング、Anki の盤での解答、棋譜モードで、チェッカーのクリックは空いている左のサイコロでそれを動かし、サイコロのクリックは順序を入れ替えてから完成した手をENTERと同じく確定し、右クリックは進行中の手を取り消します。移動元、次に移動先を入力する方法はなくなりました。

  • Anki とトレーニングは盤上で確定します：判定ボタンの代わりに、ENTERかサイコロのクリックで打った手を判定します。

  • 棋譜モードは手の前にサイコロを求めます：サイコロが入力されていないと盤は何も動かしません。二つのサイコロが入力されると、他のモードと同じく盤上で手を打ちます。

  • 新しいタブで評価：盤の右クリックで、Eval パネルに表示中の局面の#n の変化ビューが開き、元のビューは自分の局面、リスト、解析を保ちます。各ビューは自分の Eval の盤を取り戻します。

  • チャレンジ：ツールバーのチャレンジボタン（キーm）は、局面が変わるたびに、解析パネルの解析をクリックまで覆います。マッチの見直しでは、手のリストの印、損失、難易度も隠します。

  • 局面の数はどれもクリックで開きます：内訳の局面列と大悪手列、学習プランの系統（現在は学習、クイズ、Ankiの操作リスト）、Anki デッキのカウンター（期限、新規、学習中、復習中）、トーナメントの数、ゲームの印が、数えた局面をそのまま読み込みます。

  • パネルは同じヘッダー帯を共有します：タイトル、カウンター、フィルターは左、主要な操作は右端（検索、開始、対局…）に置かれ、検索は条件、履歴、保存済みを帯に収めます。

  • ライブコレクションはクエリとともに作成されます：blunderdb collection create --queryとルートcollections.create。collection evaluateは 5 000 局面まで全体を読み、実際の総数を返します。ライブコレクションから作った Anki デッキは、セッションごとにそのクエリを再実行します。

  • 棋譜モードのメタデータフォームは下書きの本体を占め、幅が許せば二列になり、棋譜は見えたままです。同じボタンかESCで入力に戻ります。

  • ヘルプの検索は、入力するにつれて出現箇所を数えて強調表示します。

  • スキーマ 2.41.0：マッチの動画ソースと各手のマーカー。各手は自身の判断のミスを持ち、すでにデータベースにあるマッチの PR は eXtreme Gammon の規則で再計算されます。2.36.0からの移行は開く際に自動で行われ、元には戻せません（付録: データベーススキーマ）。

  • 主な修正：gammonNet は、テイクまたはパスをダブル前のダブラーの判断として解析します（ロールアウトを含む）。マイグレーションは、これらの局面の古くなった gammonNet の判定を消去します。PR は、強制手、キューブの判断、印のないミスを eXtreme Gammon と同じく数えます。切り詰められた.xgファイルはコードinvalidで拒否されます。ミュートした音声と動画の音量は速度変更後も保たれます。ダイアログから始めて背景で離したドラッグは、もうダイアログを閉じません。設定の各タブはスクロール位置を保ちます。

  • マニュアル、指標と学習ツール、コマンドラインインターフェース（CLI）、ヘッドレスモード（サーバー） を参照してください。

0.38.0 (2026-10-06)

  • デュエル：blunderDB の審判のもと、gammonNet の方策で打つボットを相手にマッチ全体を対局します。サイコロは作成時に SHA-256 の指紋が公開されるシードから引かれ、ルール、スコア、時計はアプリケーションが管理します。デュエルタブ、ツールバーの « Jouer » ボタン、DUEL モードを備え、1〜25 ポイントのマッチまたはマネーセッション、初期局面・盤上の局面・選んだスコアからの開始、中断と再開に対応します。blunderdb duelとサーバーの duels.* ルートが、他の二つの形態です。

  • デュエルは盤上で打ちます：振る前は、盤かサイコロのクリックで振り、キューブのクリックでダブルを提案します。チェッカーのクリックでそれを動かし、サイコロのクリックで順序を入れ替えるか、ENTERやSPACEと同じく手を確定します。右クリックは進行中の手を取り消すか、デュエルのメニュー（パイル、投了、中断、終了）を開きます。

  • 持ち時間と判断時間：プレイヤーごとの持ち時間と毎手の無料猶予があり、時間切れは記録されるか、マッチの負けになります。デュエルの各判断にはその所要時間が付き、レビューで表示され（Durée列、プレイヤー別の要約、グラフ）、検索では tm>x（E>xと組み合わせ可能）で絞り込め、統計タブではエラーと突き合わせられます。

  • ここで対局したマッチの出自は、そのトランスクリプトの先頭で読めます。開始、持ち時間、時間切れ負けまたは終了、ボットのレベルと方策を打った gammonNet のバージョン、公開されたシードとその SHA-256 で、blunderDB を信用しなくてもすべての出目を再計算できます。

  • パイル：bキー、ツールバーのブックマーク、または盤の外でのダブルクリックで、表示中の局面をすべてのモードで脇に置き、同じ操作で外します。盤の隅のブックマークがその状態を示します。blunderdb collection pileも同じ操作を行います。

  • ロールアウトは右クリックから始まります。分析パネルの手の表からも Eval パネルからも、選んだ手（Ctrl+クリック、Shift+クリック）またはキューブ判断に対して、セッションをまたいで保持される設定（高速、標準、自由）で実行します。同じメニューで、局面を分析付きで、または選んだ手と一緒にコピーできます。

  • データベースを開いていなくても、Eval パネルで局面の配置、貼り付け、評価、ロールアウト、コピーができ、トレーニングタブではスコア、チェッカー、ベアオフ、評価が使え、import XGID=…で局面を下書き盤に置けます。

  • 盤の外での右クリックは、編集モードと Eval で Effacer la position と Position de départ を提示します。盤上で打つ手（クイズ、トランスクリプション）では、そのメニューは Recommencer から始まります。

  • デュエルの案内表示は盤の右半分の中央に、アプリの文字スケールで置かれる。手番のプレイヤーに関わらずプレイヤー1は常に下側に残り、シードのフィンガープリントは案内行のツールチップで読める。

  • 放棄・中断・取消：デュエルのメニューでマッチを放棄、一時停止、取消できる。マネーゲームでは、放棄はキューブの値でシングルゲームの負けになる。ポイントマッチは最後まで終えたものだけが記録され、保留中のデュエルのシードはどのエクスポートにも出ない。

  • Botのレベル選択は各レベルの深さを示す。値はgammonNetの表から読まれる。

  • デュエルは外部サイドを相手に遊べる。外部サイドはその背後で打つBotを宣言し（--side external:<configuration>@<engine>、sides[i].declared）、マッチの出自はそれをクライアントの宣言であり証明されたものではないと読み返す。結合シード（--combined-seed、duel contribute、duels.contribute）では、各外部サイドの寄与が封印されたシードに加わり、ダイスはそこから生成され、式は公開されている。

  • 複数のデュエルを同時に開ける：あるデュエルを開いても他のデュエルは中断されず、開いているデュエルは中断されるまで時計が進む（プロセスの停止やクラッシュの間も含む）。デスクトップ版は盤上にデュエルを一つだけ置き、離れるデュエルを中断するが、同じデータベース上でサーバーやコマンドラインが開いているデュエルには触れない。

  • マッチの記録にキューブ、プレイ、時計の列が加わる。ケイデンスと持ち時間はマッチ情報に表示され、所要時間のない時間セルにはダッシュが入る。

  • ステータスバー：ブランダーのリンクで検索が始まり、2つの数字は別々のリンクで、画面上のリストのブランダーとライブラリ全体のブランダーを指す。

  • エンジンはgammonNet v1.6.0に移行（ネットワーク strehl-prob5-512-512-256-256）。合法手は上流の順序、小さいダイスが先で出力される。

  • 記録を一度の呼び出しで実体化（厳格モード）：blunderdb transcribe --materialize とルート transcriptions.materialize はマッチを書き込むか、最初の不正なアクションを順位と理由とともに拒否し、何も書き込まない。

  • スキーマ 2.36.0：デュエルのテーブル、各判断の所要時間、宣言されたBot、外部サイドの寄与、各デュエルが開いているかどうか。2.31.0からの移行は開く際に自動で行われ、元には戻せない（付録: データベーススキーマ）。

  • 主な修正：読めないインポートファイルはコード invalid で拒否され、internalは障害専用のままです。Windows では、圧縮がファイルを実際に縮めるか、縮められなかった理由を伝えます。CTRL-Cが組み込みブラウザーのコピーと競合しなくなり、CTRL-X CTRL-Xは EVAL モードで gammonNet の評価をコピーします。

  • マニュアル、コマンドラインインターフェース（CLI）、ヘッドレスモード（サーバー） を参照してください。

0.37.0（2026-10-05）

  • トランスクリプション：紙の対局の転記用に、タブと TRANSCRIBE モードを備え、対局を一手ずつ入力できます。ダイス、21通りの出目の三角表、盤上で指した手または記法で打った手、キューブ、その場での修正、クラッシュ後に再開できる永続的な下書きに対応します。blunderdb transcribe とサーバーの transcriptions.* ルートが、他の二つの形態です。
