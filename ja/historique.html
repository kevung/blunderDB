バージョン履歴

バージョンは新しいものから古いものへと並べてあり、変更ごとに1つの項目が対応します。各バージョンの末尾には、そのバージョンがもたらしたものを詳しく説明するページへの参照が置かれています。のちのバージョンで取り消された項目には、それを置き換えたバージョンが併記されています。この一覧はソフトウェアの歴史を語るものであり、インストールされているバージョンを説明するものではありません。

更新のあとに

データベーススキーマの移行は、開いたときに自動的に行われ、元に戻せません。移行後のデータベースは blunderDB の以前のバージョンでは読めなくなるため、事前にバックアップを取っておきます（付録: データベーススキーマ）。それ以外は自動では行われません。以下のデータはいずれも遡及しないからです：

  • 古くなったポジションの再解析（0.38.0、0.40.0、0.46.0）。0.46.0 より前に書き込まれた gammonNet の解析は、それ以前のエンジン（以後 gammonNet v1.8.1）によるものです。blunderdb analyze --stale、または メンテナンス タブの 古い gammonNet 解析 の行で書き直されます。インポートされた解析には一切手を加えません。

  • 運を得るには元ファイルを再インポートする（0.33.0）。それ以前にインポートされたマッチは 運 の列にダッシュが入りますが、ダッシュはゼロではありません。運を運ばない形式（BGF、Jellyfish の .mat）が運をもたらすことは決してありません。

  • マークを得るには XG ファイルを再インポートする（0.30.0）。eXtreme Gammon で付けられたマークは、再インポート時にデータベースに反映されます。既存のコメントや分析に影響はありません。

  • gammonNet 分析の穴埋めを実行する（0.34.0）。インターフェースから、blunderdb analyzeで、あるいはサーバーモードで実行します。分析がまったくないポジションを埋めるだけで、インポートされた分析を上書きすることは決してありません。

  • gammonNet の解析の追い込みを再実行する（0.39.0）。移行は、テイクまたはパスについて受け手の判断として計算された gammonNet の評価を消去します。追い込みは、それらをダブル前のダブルした側の判断として書き直します。

  • プレイヤーを入れ替えたマッチの修復（0.40.0）。0.40.0 より前は、入れ替えるとマッチの局面が解析のない別の局面に置き換わっていました。blunderdb match repair --list は元のファイルと異なるマッチを見つけ、match repair --id またはカードの ⟲ ボタンがそのファイルから書き直します。

0.46.0 (2026-10-23)

  • gammonNet v1.8.1、半精度 ：組み込みのネットワークは float16（BGN6 形式）で格納され、アプリケーションは 1.1 MB 軽くなりました。エンジンのバージョンが変わるため、それ以前に保存された gammonNet の解析はすべて古くなり、blunderdb analyze --stale または メンテナンス タブの 古い gammonNet 解析 の行で書き直されます。

  • どのマシンでも同じ評価 ：gammonNet の解析は、x86-64 でも ARM（arm64）のプロセッサでも、ビット単位で同じ結果を返します。

  • 他のデータベース パネル （CTRL-SHIFT-A、旧「他のライブラリ」タブに代わるもの）は、開いているデータベース間の交換窓口です。各データベースについて、ポジションが あり 、 なし 、 別の解析であり のどれかを示し、移動先のデータベースがすでに持つ解析を上書きせずに、どちらの向きにもコピーします（ … へコピー 、 … から取得 ）。パネル下部のバッチがバスケットに代わります。 SHIFT-B とコンテキストメニューの 送る グループで、ポジション、マッチ、トーナメントを入れ、選んだ移動先のデータベースへ一度にコピーします。

  • 他のデータベース パネルは選択に従います ：各パネルで選択されたマッチ、トーナメント、コレクション、レッスンについて、他の各データベースがそれをすでに持っているか、そこで何を含んでいるかを示し、コピーを提案します。blunderdb elsewhere --match 、 --tournament 、 --collection 、 --lesson と across.objectElsewhere ルートも同じように答えます。

  • コピーを元に戻す ：セッション中の 2 つのデータベース間のコピー（ポジション、マッチ、トーナメント、コレクション、バッチ）は、ステータスバー（ コピーを元に戻す (n) ）から新しい順に元に戻せます。元に戻すのはコピーが作成したものだけで、作成したものがその後変更されていれば拒否されます。

  • 分割画面はボード領域だけを 2 つに分けます ：各ペインは自分のデータベースと側を保ち、アクティブなペインはその色で縁取られ、もう一方は薄く表示されます。クリックまたは CTRL-ALT-← / → でペインを切り替え、ポジションを一方のペインから他方へドラッグするとコピーされ、パネルとステータスバーはアクティブなデータベースに従います。

  • サブメニュー付きのコンテキストメニュー ：ボードと、マッチ、トーナメント、コレクションの各パネルの行は、共通のカタログからアクションを取り、矢印キーでたどれるサブメニュー（▸）に整理されます。ポジションの状態に応じて 確認済みにする または 確認済みを外す 、 GNUbg ID をコピー は GNU Backgammon が読み込むポジション ID とマッチ ID を返し、 この手でマッチを開く はそのポジションを打った最初のマッチを開きます。blunderdb gnubgid と positions.gnubgId ルートは同じ ID を計算します。

  • タブ ：幅に収まらなくなると、タブの列は 2 つの矢印の間でスクロールし、グラデーションが隠れたタブのある端を示し、 すべてのビュー メニュー（ ∨ ）が各データベースのビューを一覧します。タブをドラッグするとそのグループ内のビューが並べ替わり、グループの見出しをドラッグするとグループ全体が移動します。

  • CTRL-S は表示中の gammonNet 評価も保存します （Eval パネル）：ボードの判定（ダイスがあれば手、なければキューブ）がポジションとともに書き込まれます。データベースがすでに持つ解析はそのまま保たれます。

  • 3 から 25 までの各 n について正確な Neil 数 を 参照データ パネルに、正確な分数で表示します。基準点は立体、補間値は斜体です。

  • トランスクリプション ：ある出目の候補手はその合法手すべてで、0-ply で順位付けされます。 インポート ボタン（下書き一覧ではキー i ）は .mat ファイルまたはトランスクリプション文書を下書きとして開き、transcriptions.import ルートも同じことをします。サーバーが返すトランスクリプションの状態には video_source と、各アクションのマーカーと所要時間が含まれます。

  • 統計 ：stats summary と stats.summary ルートは統計の公開部分を返し、最悪のミスやマッチごとの詳細は含みません。stats windows --by-phase （ stats.prByWindow ）は各ウィンドウをゲームのフェーズごとに分け、list --type timeerrors --ids （ stats.timeErrors ）はマッチの一覧に限定され、stats.tournamentReviews ルートは複数のプレイヤーのレビューを 1 回の呼び出しで返します。

  • トーナメントの運営 ：パーセントで定めた賞金表は、最大剰余法により整数単位で支払われます。支払総額は丸めた分配総額に一致し、減少する賞金表は減少する金額を与えます。

  • 主な修正：#tag コマンドはコメントに # を残し、#tag 検索で見つかるようになり、末尾の句読点を含めてすでにあるタグを追加しません。解析の補完は、解析に XGID しかないポジションも埋めます。グループを切り替えてもボードが動かなくなりました。

  • 比較と交換：「他のデータベース」パネル、コンテキストメニュー、複数のライブラリを開く、参照データパネル、記譜パネル、大会を運営する、ヘッドレスモード（サーバー） を参照してください。

0.45.0 (2026-10-21)

  • 複数のライブラリを同時に開く：開いた各データベースはファイル名を掲げた色付きの見出しの下にタブのグループを作り、別のグループのタブをクリックすると、そのライブラリとそのビューが一度に有効になります。CTRL-SHIFT-Oまたは open_groupは新しいグループでデータベースを開き、CTRL-SHIFT-PageUp/ PageDownはライブラリを順に移ります。インポート、監視フォルダー、一括解析は、それを始めたライブラリに結び付いたままです。

  • ライブラリ間のコピー：ポジション、マッチ、コレクション、レッスンを別のグループの見出しへドラッグすると、バックグラウンドでそこへコピーされます。SHIFT-Bは一度に注ぎ込むバスケットを満たし、南京錠はグループへの書き込みを禁じます。blunderdb transferとサーバーの across.transferPullルートも同じコピーを行います。

  • 他のライブラリタブ（CTRL-SHIFT-A）は、表示中のポジションについて、開いている他のライブラリが知っていることを示します。アクティブなライブラリのしきい値で判定した解析、異なるエクイティ表の指摘、コメントとその署名者、そのポジションが指されたマッチ、近いポジションです。xキーを押している間、盤の位置に他のライブラリのポジションが描かれます。blunderdb elsewhereと across.positionElsewhereルートがその別の形です。

  • 分割画面（◫ ボタン、CTRL-SHIFT-X）は、アクティブなグループと別のグループの閲覧専用ビューアを並べて表示します。ビューアをクリックすると役割が入れ替わります。幅 1280 ピクセル以上が必要です。

  • 2 台のマシンの同期：差分エクスポート（export --type database --incremental）は、同じ宛先への前回のエクスポート以降に入ったものだけを運び、監視フォルダーはそこに届いた .dbを統合します。運ばれるのは追加分だけです。

  • コメントに署名が付く：透かし入りのエクスポートは、あなたのコメントに発行者 ID で署名し、受け取った人は誰が書いたか、途中で改変されていないかを確認できます。

  • 参照データパネル（CTRL-SHIFT-R、referenceまたは ref）は、Kazaross-XG2 の MET、テイクポイント（キューブ 2 と 4、ライブとデッドを並べて）、ギャモン値（キューブ 1、2、4）、スコア別の集約表示、ニールの数をまとめ、データベースなしでもデュエル中でも参照できます。met、tp…、gv…はそれぞれのタブでパネルを開きます。

  • レッスンを単体の HTML ページとしてエクスポート：タイトル、説明、各ステップの本文と盤面、各ポジションの解析をクイズの答えのように折りたたんで収めます。blunderdb lesson export --htmlとサーバーの lessons.htmlルートも同じページを作ります。

  • クラブのネットワークで大会を表示：Direction が小さな Web サーバーを起動し、そのアドレスの QR コードを表示します。同じネットワークの携帯電話で、トーナメント表、組み合わせ、結果、順位を 10 秒ごとの更新で追えます。

  • 高速化：アプリケーションの起動が速くなり、サイズが 3 MB 小さくなりました。E フィルター（E>n）は各ポジションの手を比較しなくなり、学習統計（stats effect）、CSV エクスポート、データベースのエクスポートが速くなり、エクスポートが書く解析は約 5 分の 1 の大きさです。マッチパネルは切り替えのたびに並べ替えとフィルターを保ち、組み込みヘルプは待たずに開き直せます。データベースのマッチごとの統計は開いた直後からバックグラウンドで計算され、大会パネルとプレイヤーパネルを待たせません。

  • サーバー側：blunderdb call --backend remote --dsn <URL>は呼び出しを serveデーモン経由で行います。負荷の高い SQLite デーモンは内部エラーではなく Retry-After付きの 503 を返し、--heavy-slotsは同時に行う重い読み取りの数を制限し、マッチごとの統計は起動時に埋められます。blunderdb migrateはバッチでコピーし（30 万ポジションのデータベースで 2 時間以上かかっていたところを 7 分）、レッスンも運びます。

  • 主な修正：組み込みヘルプを開き直しても固まらなくなりました。存在しないコレクションの変更、削除、凍結は、内部エラーや偽の成功ではなく、そのものとしてサーバーに拒否されます。

  • 複数のライブラリを開く、比較と交換：「他のデータベース」パネル、2台のマシンを同期する、参照データパネル、レッスン、大会を運営する、transfer — ライブラリから別のライブラリへコピーする、ヘッドレスモード（サーバー） を参照してください。

  • サーバー側：search.findはピップカウントと日付で並べ替え、analyses.queueStatusは解析キューを返し、統計は対戦相手で絞り込めます。positions.setIndividuallyImportedは局面の「手動で取り込み」の印を外し、matches.lastVisitedは最後に取り込んだマッチではなく最後に訪れたマッチを返します。blunderdb statsは--opponentを受け付けます。

  • トレーニングパネル、openingbook — このスコアでどの手か、API コントラクト を参照してください。

0.42.0 (2026-10-17)

  • ENTER でトレーニングの問題を続けて解く：判断またはオープニングの練習中、フォーカスが入力欄・ボタン・ウィンドウの外にあればどこでも、ENTER で盤上で打った手を確定し、判定が表示されたら次の問題へ進むか、セッションを終了します。素早く 2 回押しても、解答が 2 回採点されることはありません。

  • サーバー側：matches.byPositionルートは、ある局面で手が指されたマッチを一覧にします。また、PostgreSQL データベースへの XG ファイルのインポートは、局面あたりのクエリ数が半分になり、2 倍速くなりました。

  • 主な修正：ある局面で一方のチェッカーが 16 枚あるマッチファイルは、内部エラーではなく、無効としてサーバーに拒否されます。

  • トレーニングパネル、キーボードショートカット、openingbook — このスコアでどの手か、オープニングブック：差、95 % 信頼区間、同等、API コントラクト を参照してください。
