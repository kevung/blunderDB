API コントラクト

冪等性

ほとんどのメソッドには特別な仕組みは一切必要ありません。読み取りには副作用がなく、positions.save(他の positions.*と同様)は Zobrist コンテンツハッシュのおかげで本質的に冪等です — 同じポジションを2回保存しても同じ行が返され、重複が生じることはありません。この性質を持たないメソッドが3つあり(2回の呼び出しは2つの異なる効果になります)、任意の Idempotency-Key ヘッダーを受け付けます。同じキーで再試行された呼び出しは、その効果を繰り返す代わりに最初の試行の結果を返します — 上記の表の「(Idempotency-Key)」の印を参照してください。他のどのメソッドもこのヘッダーを必要とせず、受け付けません。
