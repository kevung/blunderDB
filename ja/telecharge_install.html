ダウンロードとインストール

blunderDB はインストール不要の単一実行ファイルとして提供されます。

blunderDB の最新バージョンは MIT ライセンスの下で利用可能です：

  • Windows 版：https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-windows-0.36.0.exe

    初回起動時に、Windows は SmartScreen の警告（「WindowsによってPCが保護されました」）を表示します。これは想定どおりです。実行ファイルにデジタル署名がないためです。必要な対処を参照してください。

  • Linux 版：https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-0.36.0

  • Mac 版：https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-macos-0.36.0.zip

    macOS も同じ理由で同様の警告を出します。必要な対処を参照してください。

オフラインで参照するには、このドキュメントを PDF 形式でダウンロードすることもできます：https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-0.36.0-ja.pdf

注釈

blunderDB はグラフィカルインターフェースのレンダリングに Webview2 を使用します。Webview2 はすでにオペレーティングシステムにネイティブに存在している可能性が高いです。そうでない場合、blunderDB の初回実行時にダウンロードとインストールが提案されます。ユーザーによる操作は不要です。

注釈

同じく初回起動時に、blunderDB は Eval パネルが使う二つのベアオフテーブルをバックグラウンドで計算します。1 コアで約 6 秒、何も尋ねられることはなく、その間もアプリケーションは通常どおり使えます。設定の Bearoff タブを参照してください。

どのファイルを選ぶか

リリースページ で公開される各バージョンには 30 個ほどのファイルが添付されています。下の表はお使いのシステムに応じてどれを取るべきかを示します。x.y.z はバージョン番号に置き換えてください。

Fedora, openSUSE

blunderdb-x.y.z.x86_64.rpm

sudo dnf install ./blunderdb-x.y.z.x86_64.rpm

Arch Linux, Manjaro

AUR パッケージ blunderdb-bin

Flatpak が使える任意の Linux ディストリビューション

blunderDB-x.y.z.flatpak

サーバー（serve モード、Docker）

amd64 と x86_64 のファイルは Intel または AMD のプロセッサ向けで、つまりほとんどのデスクトップパソコン向けです。arm64 と aarch64 のファイルは64ビットの ARM プロセッサ向けです。Raspberry Pi 4 と 5、Linux を動かしている Apple シリコンの Mac、ARM のサーバーなどです。迷ったときは uname -m が答えます。x86_64 か aarch64 です。AUR パッケージの blunderdb-bin は両方に対応し、自動で選びます。

ページ上のその他のファイルは、生の Linux バイナリ（後述）、winget と Homebrew のマニフェスト（winget と Homebrew のマニフェスト を参照）、9 言語の PDF ドキュメント、および .sha256 ハッシュです。

ダウンロードの検証

ここで説明する二つの検証は任意であり、上級者向けです。コマンドラインで行うもので、インストール作業の一部ではありません。この節を読み飛ばしても支障はありません。

公開される各ファイルには、同じ名前に .sha256 を付けたファイルとして SHA-256 ハッシュが添付されています。両方を同じフォルダにダウンロードし、受け取ったファイルが公開されたものと一致することを確認してください：

sha256sum -c blunderdb_x.y.z_amd64.deb.sha256        # Linux
shasum -a 256 -c blunderDB-macos-x.y.z.zip.sha256   # macOS

Get-FileHash .\blunderDB-windows-x.y.z.exe -Algorithm SHA256   # Windows

Linux と macOS ではコマンドが OK と表示します。Windows では表示された値を .sha256 ファイルの内容と比較してください。この検証は、コード署名がない状況で利用できる保証です（Windows 付録：Windows が起動をブロックしたときの対処 と Mac 付録：blunderDB の起動ブロックについて を参照）。

公開される各ファイルには、GitHub リポジトリの公式ビルド実行によって実際に生成されたことを証明する来歴証明(SLSA、Sigstore 経由)も添付されており、鍵を管理する必要はありません。

gh attestation verify blunderdb_x.y.z_amd64.deb --repo kevung/blunderDB

Linux へのインストール

Linux 向けには複数の形式が提供されています。以下のパッケージとアーカイブは blunderDB を自動的に実行可能にします。ブラウザ経由でダウンロードした生のバイナリとは異なり、ダウンロードや更新のたびに chmod +x を実行する必要がありません。アプリケーションメニューにエントリも作成されます。

注釈

.deb パッケージと.rpm パッケージは、.dbx 拡張子（パスワード付きでエクスポートしたデータベース。データベースの配布：出所とパスワード を参照）を blunderDB に関連付けます。誰かから受け取った.dbx ファイルをダブルクリックすると、そのまま開きます。通常のデータベースの.db 拡張子は意図的に関連付けません。あまりに一般的で、他のソフトウェアと共用されているためです。ただし blunderDB の開くメニューからは通常どおり開けます。

ネイティブパッケージ (.deb / .rpm)

Debian、Ubuntu、Linux Mint (.deb)、および Fedora、openSUSE (.rpm) で推奨される方法です。パッケージマネージャが適切な webkit2gtk 依存関係を自動的にインストールします。x.y.z をダウンロードしたバージョンに置き換えてください：

sudo apt install ./blunderdb_x.y.z_amd64.deb     # Debian / Ubuntu / Mint
sudo dnf install ./blunderdb-x.y.z.x86_64.rpm    # Fedora / openSUSE

Arch Linux (AUR)

blunderdb-bin パッケージは AUR で利用でき、AUR ヘルパーによって自動的に更新されます：

yay -S blunderdb-bin      # ou : paru -S blunderdb-bin

Flatpak

バンドル blunderDB-x.y.z.flatpak は Flatpak がインストールされている任意のディストリビューションで動作します。GNOME 47 ランタイムに依存しており、なければ Flatpak が Flathub からダウンロードします：

flatpak install ./blunderDB-x.y.z.flatpak
flatpak run io.github.kevung.blunderDB

バンドルはダウンロードしたファイルからインストールし、次のバージョンのものをインストールすることで更新します。アプリケーションはデータベースを開いたり保存したりするためにホームフォルダにアクセスできます。コマンドライン（コマンドラインインターフェース（CLI））は flatpak run io.github.kevung.blunderDB <コマンド> で利用できます。

.tar.gz アーカイブ

その他のディストリビューション向け。アーカイブを展開すると実行ビットが保持されるため、chmod は不要です：

tar xzf blunderDB-linux-webkit2gtk-4.1-x.y.z.tar.gz
cd blunderDB-linux-webkit2gtk-4.1-x.y.z
./blunderDB

注釈

アーカイブ内の実行ファイルの名前は大文字を含む blunderDB です。.deb、.rpm、AUR、Flatpak の各パッケージはさらに小文字のリンク blunderdb をインストールします。これはコマンドラインのドキュメント（コマンドラインインターフェース（CLI））が使う名前で、アーカイブにも実行ファイルの隣に同じリンクが含まれています。PATH に置くには：ln -s "$PWD/blunderDB" ~/.local/bin/blunderdb

生のバイナリ (上級者向けの方法)

生のバイナリ https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-0.36.0 も引き続き利用できます。ブラウザはダウンロード時に実行ビットを削除するため、最初の実行前に復元する必要があります：

chmod +x ./blunderDB-linux-x.y.z

注釈

webkit2gtk ライブラリのバージョンに応じて 2 つの Linux 版が公開されています。libwebkit2gtk-4.0.so.37: cannot open shared object file というエラーが表示される場合、お使いのディストリビューションは webkit2gtk-4.1 を使用しています。.deb/.rpm パッケージ、AUR パッケージを使用するか、専用版 https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-webkit2gtk-4.1-0.36.0 をダウンロードしてください。ネイティブパッケージは正しい依存関係を自動的に選択します。

Docker イメージ（サーバーモード）

サーバーモード（ヘッドレスモード（サーバー））にはデスクトップアプリケーションは不要です。各バージョンは GitHub のレジストリにイメージ ghcr.io/kevung/blunderdb-serve を linux/amd64 と linux/arm64 向けに、バージョンタグと latest タグで公開します：

docker pull ghcr.io/kevung/blunderdb-serve:x.y.z

起動、設定、および認証プロキシに関する警告は 公開イメージ に記載されています。

winget と Homebrew のマニフェスト

各リリースは、リリースページに winget のマニフェスト（blunderDB-winget-manifests-x.y.z.zip）と Homebrew のフォーミュラ（blunderdb-x.y.z.rb）を提供しており、これらのパッケージマネージャでローカルファイルから blunderDB をインストールしたい人向けです。どちらも winget や Homebrew の公開リポジトリには登録されていません。どちらも実行ファイルの性質を変えるものではありません：署名されないままであり、以下に説明する警告がそのまま当てはまります。

Windows と Mac に関する警告

警告

Windows では、blunderDB の実行を拒否する場合があります。理由と回避方法については Windows 付録：Windows が起動をブロックしたときの対処 を参照してください。

警告

Mac では、blunderDB の実行を拒否する場合があります。理由と回避方法については Mac 付録：blunderDB の起動ブロックについて を参照してください。
