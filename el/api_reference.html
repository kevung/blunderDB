Σύμβαση API

Αυτό το παράρτημα παράγεται από τον πηγαίο κώδικα (go run ./cmd/openapi-gen· βλ. openapi.yaml στη ρίζα του αποθετηρίου για την πλήρη σύμβαση, μαζί με τα σχήματα): μην το επεξεργάζεστε απευθείας, η επόμενη παραγωγή θα αντικαταστήσει κάθε αλλαγή. Κάθε οικογένεια ομαδοποιεί τις μεθόδους POST /v1/<οικογένεια>.<μέθοδος> που εκθέτει ο δαίμονας (βλ. Λειτουργία χωρίς γραφικό περιβάλλον (διακομιστής)), με τη μορφή απόκρισής τους (JSON, ή NDJSON για μια ροή λίστας) και, όπου υπάρχει, μια σημείωση για την προαιρετική κεφαλίδα Idempotency-Key.

Ιδεμποτότητα

Οι περισσότερες μέθοδοι δεν χρειάζονται κανέναν ειδικό μηχανισμό: οι αναγνώσεις δεν έχουν παρενέργειες, και η positions.save (όπως και οι υπόλοιπες positions.*) είναι εκ φύσεως ιδεμπότοτη χάρη στο hash περιεχομένου Zobrist — η αποθήκευση της ίδιας θέσης δύο φορές επιστρέφει την ίδια γραμμή, ποτέ ένα αντίγραφο. 3 μέθοδοι δεν έχουν αυτή την ιδιότητα (δύο κλήσεις είναι δύο διακριτά αποτελέσματα) και δέχονται μια προαιρετική κεφαλίδα Idempotency-Key: μια κλήση που επαναλαμβάνεται με το ίδιο κλειδί επιστρέφει το αποτέλεσμα της πρώτης προσπάθειας αντί να επαναλάβει το αποτέλεσμά της — βλ. την ένδειξη «(Idempotency-Key)» στον παραπάνω πίνακα. Καμία άλλη μέθοδος δεν χρειάζεται ή δέχεται αυτή την κεφαλίδα.
