Λήψη και εγκατάσταση

Το blunderDB είναι ένα μοναδικό εκτελέσιμο αρχείο που δεν απαιτεί καμία εγκατάσταση.

Η τελευταία έκδοση του blunderDB είναι διαθέσιμη με άδεια MIT:

  • για Windows: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-windows-0.36.0.exe

    Κατά την πρώτη εκκίνηση, τα Windows εμφανίζουν μια προειδοποίηση SmartScreen («Τα Windows προστάτευσαν τον υπολογιστή σας»). Αυτό είναι αναμενόμενο: το εκτελέσιμο δεν είναι ψηφιακά υπογεγραμμένο. Δείτε τι πρέπει να κάνετε.

  • για Linux: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-0.36.0

  • για Mac: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-macos-0.36.0.zip

    Το macOS εμφανίζει μια παρόμοια προειδοποίηση, για τον ίδιο λόγο: δείτε τι πρέπει να κάνετε.

Για ανάγνωση εκτός σύνδεσης, μπορείτε επίσης να κατεβάσετε αυτή την τεκμηρίωση σε μορφή PDF: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-0.36.0-el.pdf

Σημείωση

Το blunderDB χρησιμοποιεί το Webview2 για την απόδοση του γραφικού περιβάλλοντος. Είναι πολύ πιθανό το Webview2 να είναι ήδη εγκατεστημένο εγγενώς στο λειτουργικό σας σύστημα. Σε αντίθετη περίπτωση, η πρώτη εκτέλεση του blunderDB θα προτείνει τη λήψη και την εγκατάστασή του. Δεν απαιτείται καμία ενέργεια από τον χρήστη.

Σημείωση

Πάντα κατά την πρώτη εκκίνηση, το blunderDB υπολογίζει στο παρασκήνιο τους δύο πίνακες bearoff που χρησιμοποιεί ο πίνακας Eval: περίπου έξι δευτερόλεπτα σε έναν πυρήνα, χωρίς να ζητήσει τίποτα, και η εφαρμογή χρησιμοποιείται κανονικά στο μεταξύ. Δείτε την καρτέλα Bearoff των ρυθμίσεων.

Ποιο αρχείο να επιλέξω;

Κάθε έκδοση που δημοσιεύεται στη σελίδα των εκδόσεων συνοδεύεται από καμιά τριανταριά αρχεία. Ο παρακάτω πίνακας δείχνει ποιο να πάρετε ανάλογα με το σύστημά σας· αντικαταστήστε το x.y.z με τον αριθμό της έκδοσης.

Διακομιστής (λειτουργία serve, Docker)

εικόνα ghcr.io/kevung/blunderdb-serve

docker pull ghcr.io/kevung/blunderdb-serve:x.y.z

Τα αρχεία amd64 και x86_64 είναι για επεξεργαστή Intel ή AMD, δηλαδή σχεδόν για κάθε επιτραπέζιο υπολογιστή. Τα αρχεία arm64 και aarch64 είναι για επεξεργαστή ARM 64 bit: Raspberry Pi 4 και 5, Mac με τσιπ Apple που τρέχουν Linux, διακομιστές ARM. Σε περίπτωση αμφιβολίας, το uname -m απαντά: x86_64 ή aarch64. Το πακέτο AUR blunderdb-bin καλύπτει και τα δύο και επιλέγει μόνο του.

Τα υπόλοιπα αρχεία της σελίδας είναι τα ακατέργαστα εκτελέσιμα Linux (βλ. παρακάτω), τα manifests winget και Homebrew (βλ. Μανιφέστα winget και Homebrew), η τεκμηρίωση σε PDF σε εννέα γλώσσες και τα αποτυπώματα .sha256.

Επαλήθευση μιας λήψης

Οι δύο έλεγχοι που περιγράφονται εδώ είναι προαιρετικοί και προορίζονται για προχωρημένους χρήστες: γίνονται από τη γραμμή εντολών και δεν αποτελούν μέρος της εγκατάστασης. Η παράλειψη αυτής της ενότητας δεν εμποδίζει τίποτα.

Κάθε δημοσιευμένο αρχείο συνοδεύεται από το αποτύπωμα SHA-256 του, σε ένα αρχείο με το ίδιο όνομα και την κατάληξη .sha256. Κατεβάστε και τα δύο στον ίδιο φάκελο και επαληθεύστε ότι το αρχείο που λάβατε είναι αυτό που δημοσιεύτηκε:

sha256sum -c blunderdb_x.y.z_amd64.deb.sha256        # Linux
shasum -a 256 -c blunderDB-macos-x.y.z.zip.sha256   # macOS

Get-FileHash .\blunderDB-windows-x.y.z.exe -Algorithm SHA256   # Windows

Σε Linux και macOS η εντολή εμφανίζει OK· στα Windows συγκρίνετε την τιμή που εμφανίζεται με το περιεχόμενο του αρχείου .sha256. Αυτός ο έλεγχος είναι η εγγύηση που διατίθεται ελλείψει υπογραφής κώδικα (βλ. Παράρτημα Windows: τι να κάνετε αν τα Windows μπλοκάρουν την εκκίνηση και Παράρτημα Mac: Πιθανός αποκλεισμός του blunderDB).

Κάθε δημοσιευμένο αρχείο συνοδεύεται επίσης από μια βεβαίωση προέλευσης (SLSA, μέσω Sigstore), η οποία αποδεικνύει ότι παράχθηκε πράγματι από την επίσημη εκτέλεση δόμησης (build) του αποθετηρίου στο GitHub, χωρίς να χρειάζεται διαχείριση κλειδιού:

gh attestation verify blunderdb_x.y.z_amd64.deb --repo kevung/blunderDB

Εγκατάσταση σε Linux

Για το Linux προσφέρονται διάφορες μορφές. Τα παρακάτω πακέτα και αρχεία καθιστούν το blunderDB αυτόματα εκτελέσιμο: σε αντίθεση με το ακατέργαστο εκτελέσιμο που λαμβάνεται μέσω προγράμματος περιήγησης, αποφεύγουν την εκτέλεση της εντολής chmod +x σε κάθε λήψη ή ενημέρωση. Δημιουργούν επίσης μια καταχώριση στο μενού εφαρμογών.

Σημείωση

Τα πακέτα .deb και .rpm συσχετίζουν την επέκταση .dbx (μια βάση εξαγόμενη με κωδικό, βλ. Διανομή μιας βάσης: προέλευση και κωδικός πρόσβασης) με το blunderDB: το διπλό κλικ σε ένα αρχείο .dbx που λάβατε από κάποιον το ανοίγει απευθείας. Η επέκταση .db μιας συνηθισμένης βάσης δεν συσχετίζεται σκόπιμα — είναι υπερβολικά γενική και κοινή με άλλα προγράμματα — αλλά παραμένει κανονικά ανοίξιμη από το μενού Άνοιγμα του blunderDB.

Εγγενή πακέτα (.deb / .rpm)

Συνιστώμενη μέθοδος σε Debian, Ubuntu και Linux Mint (.deb) καθώς και σε Fedora και openSUSE (.rpm). Ο διαχειριστής πακέτων εγκαθιστά αυτόματα την κατάλληλη εξάρτηση webkit2gtk. Αντικαταστήστε το x.y.z με την έκδοση που λάβατε:

sudo apt install ./blunderdb_x.y.z_amd64.deb     # Debian / Ubuntu / Mint
sudo dnf install ./blunderdb-x.y.z.x86_64.rpm    # Fedora / openSUSE

Arch Linux (AUR)

Το πακέτο blunderdb-bin είναι διαθέσιμο στο AUR και ενημερώνεται αυτόματα από τους βοηθούς AUR:

yay -S blunderdb-bin      # ou : paru -S blunderdb-bin

Flatpak

Το bundle blunderDB-x.y.z.flatpak λειτουργεί σε κάθε διανομή όπου είναι εγκατεστημένο το Flatpak. Βασίζεται στο περιβάλλον GNOME 47, το οποίο το Flatpak κατεβάζει από το Flathub αν λείπει:

flatpak install ./blunderDB-x.y.z.flatpak
flatpak run io.github.kevung.blunderDB

Το bundle εγκαθίσταται από το αρχείο που κατεβάσατε και ενημερώνεται εγκαθιστώντας αυτό της επόμενης έκδοσης. Η εφαρμογή έχει πρόσβαση στον προσωπικό φάκελο για να ανοίγει και να αποθηκεύει βάσεις. Η γραμμή εντολών (Διεπαφή γραμμής εντολών (CLI)) είναι διαθέσιμη μέσω flatpak run io.github.kevung.blunderDB <εντολή>.

Αρχείο .tar.gz

Για άλλες διανομές. Η εξαγωγή ενός αρχείου διατηρεί το bit εκτέλεσης, οπότε δεν χρειάζεται chmod:

tar xzf blunderDB-linux-webkit2gtk-4.1-x.y.z.tar.gz
cd blunderDB-linux-webkit2gtk-4.1-x.y.z
./blunderDB

Σημείωση

Το εκτελέσιμο του αρχείου ονομάζεται blunderDB, με κεφαλαία. Τα πακέτα .deb, .rpm, AUR και Flatpak εγκαθιστούν επιπλέον τον σύνδεσμο blunderdb με πεζά, το όνομα που χρησιμοποιεί η τεκμηρίωση της γραμμής εντολών (Διεπαφή γραμμής εντολών (CLI))· το αρχείο περιέχει τον ίδιο σύνδεσμο δίπλα στο εκτελέσιμο. Για να τον έχετε στο PATH σας: ln -s "$PWD/blunderDB" ~/.local/bin/blunderdb.

Ακατέργαστο εκτελέσιμο (προχωρημένη μέθοδος)

Το ακατέργαστο εκτελέσιμο https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-0.36.0 παραμένει διαθέσιμο. Επειδή ένα πρόγραμμα περιήγησης αφαιρεί το bit εκτέλεσης κατά τη λήψη, πρέπει να το αποκαταστήσετε πριν από την πρώτη εκτέλεση:

chmod +x ./blunderDB-linux-x.y.z

Σημείωση

Δημοσιεύονται δύο παραλλαγές Linux ανάλογα με την έκδοση της βιβλιοθήκης webkit2gtk. Εάν λάβετε το σφάλμα libwebkit2gtk-4.0.so.37: cannot open shared object file, η διανομή σας χρησιμοποιεί webkit2gtk-4.1: χρησιμοποιήστε το πακέτο .deb/.rpm, το πακέτο AUR ή κατεβάστε την ειδική έκδοση https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-webkit2gtk-4.1-0.36.0. Τα εγγενή πακέτα επιλέγουν αυτόματα τη σωστή εξάρτηση.

Εικόνα Docker (λειτουργία διακομιστή)

Η λειτουργία διακομιστή (Λειτουργία χωρίς γραφικό περιβάλλον (διακομιστής)) δεν χρειάζεται την εφαρμογή επιφάνειας εργασίας: κάθε έκδοση δημοσιεύει την εικόνα ghcr.io/kevung/blunderdb-serve στο μητρώο του GitHub, για linux/amd64 και linux/arm64, με την ετικέτα της έκδοσης και με την ετικέτα latest:

docker pull ghcr.io/kevung/blunderdb-serve:x.y.z

Η εκκίνηση, η ρύθμιση και η προειδοποίηση για τον διαμεσολαβητή ταυτοποίησης περιγράφονται στο Δημοσιευμένη εικόνα.

Μανιφέστα winget και Homebrew

Κάθε έκδοση παρέχει στη σελίδα των εκδόσεων ένα μανιφέστο winget (blunderDB-winget-manifests-x.y.z.zip) και μια φόρμουλα Homebrew (blunderdb-x.y.z.rb), για όποιον θέλει να εγκαταστήσει το blunderDB μέσω αυτών των διαχειριστών πακέτων από τοπικό αρχείο. Κανένα από τα δύο δεν περιλαμβάνεται στα δημόσια αποθετήρια του winget ή του Homebrew. Κανένα από τα δύο δεν αλλάζει τη φύση του εκτελέσιμου: παραμένει ανυπόγραφο, και οι προειδοποιήσεις που περιγράφονται παρακάτω ισχύουν ως έχουν.

Προειδοποιήσεις για Windows και Mac

Προειδοποίηση

Στα Windows, είναι πιθανό να υπάρξει διστακτικότητα στην εκτέλεση του blunderDB. Δείτε Παράρτημα Windows: τι να κάνετε αν τα Windows μπλοκάρουν την εκκίνηση για να κατανοήσετε γιατί και πώς να παρακάμψετε τυχόν εμπόδια.

Προειδοποίηση

Στο Mac, είναι πιθανό να υπάρξει διστακτικότητα στην εκτέλεση του blunderDB. Δείτε Παράρτημα Mac: Πιθανός αποκλεισμός του blunderDB για να κατανοήσετε γιατί και πώς να παρακάμψετε τυχόν εμπόδια.
