blunderDB

A backgammon blunder analysis tool: import your matches from eXtreme Gammon, GnuBG and BGBlitz, store every position once, and search them by structure and by mistake.

A built-in evaluator (gammonNet) judges any position offline — no internet connection, no external engine to install.

Free and open source (MIT), one binary, five modes: desktop app, command line, headless server.

Windows (.exe) macOS (.zip) Linux (.deb)

Every asset is checksummed and attestable — see the full install guide for Fedora, Arch, Flatpak, arm64 and raw binaries.
