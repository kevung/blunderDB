Tastenkürzel

Datenbank

Tastenkürzel

Aktion

STRG-N

Eine neue Datenbank erstellen.

STRG-O

Eine bestehende Datenbank öffnen.

STRG-UMSCHALT-I

Eine Datenbank in diese zusammenführen.

STRG-UMSCHALT-S

Die Datenbank exportieren.

STRG-Q

blunderDB schließen.

STRG-M

Die Metadaten der Datenbank bearbeiten.

Position

Tastenkürzel

Aktion

STRG-I

Eine oder mehrere Positionen/Matches aus einer Datei importieren (xg, xgp, sgf, mat, txt, bgf).

STRG-UMSCHALT-F

Einen Ordner mit Match-/Positionsdateien rekursiv importieren.

STRG-C

Eine Position in die Zwischenablage kopieren.

STRG-X

Das Bild des Boards in die Zwischenablage kopieren (PNG).

STRG-X STRG-X

Das Bild des Boards mit Analyse in die Zwischenablage kopieren (PNG).

STRG-V

Eine Position aus der Zwischenablage einfügen (automatische Formaterkennung).

STRG-S

Eine Position speichern.

STRG-U

Eine Position aktualisieren.

Entf

Aktuelle Stellung löschen (Bestätigung erforderlich).

RÜCKTASTE

Board, Dopplerwürfel, Spielstand und Würfel zurücksetzen.

STRG-G

Die Metadaten der Position anzeigen.

Navigation

Tastenkürzel

Aktion

STRG-R

Alle Positionen aus der Datenbank neu laden.

Bild-auf, h

Erste Position / Vorheriges Spiel (Match-Navigation).

LINKS, k

Vorherige Position.

RECHTS, j

Nächste Position.

OBEN, k

Vorheriger Zug (wenn ein Zug in der Analyse ausgewählt ist).

UNTEN, j

Nächster Zug (wenn ein Zug in der Analyse ausgewählt ist).

Bild-ab, l

Letzte Position / Nächstes Spiel (Match-Navigation).

r

Eine zufällige Position laden.

Anzeige

Tastenkürzel

Aktion

STRG-LINKS

Board-Ausrichtung nach links.

STRG-RECHTS

Board-Ausrichtung nach rechts.

p

Pipcount ein-/ausblenden.

Aktionen

Tastenkürzel

Aktion

TAB

Das Suchfenster öffnen (Positionseditor).

LEERTASTE

Die Befehlszeile öffnen.

Werkzeuge

Tastenkürzel

Aktion

STRG-L

Die Analyse ein-/ausblenden.

STRG-P

Die Kommentare ein-/ausblenden.

STRG-K

Das Anki-Fenster ein-/ausblenden (verteiltes Wiederholen).

STRG-F

Das Suchfenster ein-/ausblenden.

STRG-Tab

Das Match-Fenster ein-/ausblenden.

STRG-B

Das Sammlungen-Fenster ein-/ausblenden.

STRG-Y

Das Turnier-Fenster ein-/ausblenden.

STRG-D

Das Statistik-Fenster ein-/ausblenden.

STRG-E

Das Eval-Panel ein-/ausblenden.

?

Die Hilfe ein-/ausblenden.

Ansichts-Reiter

Tastenkürzel

Aktion

STRG-T

Eine neue Ansicht erstellen (Kopie der aktuellen Ansicht).

STRG-W

Die aktuelle Ansicht schließen.

STRG-Bild-auf, UMSCHALT-J

Vorherige Ansicht.

STRG-Bild-ab, UMSCHALT-K

Nächste Ansicht.

STRG-1 … STRG-9

Direkt zur n-ten Ansicht springen.

Doppelklick auf den Reiter

Die Ansicht umbenennen.

Befehlszeile

Tastenkürzel

Aktion

OBEN

Im Befehlsverlauf nach oben blättern.

UNTEN

Im Befehlsverlauf nach unten blättern.

Suchverlauf

Tastenkürzel

Aktion

Klick

Eine Suche auswählen/abwählen (Position anzeigen).

Doppelklick

Die Suche ausführen.

Filterbibliothek

Tastenkürzel

Aktion

Klick

Einen Filter auswählen/abwählen (Position anzeigen).

Doppelklick

Die Suche des Filters ausführen.

Analyse-Fenster

Tastenkürzel

Aktion

Klick

Einen Zug auswählen/abwählen (Pfeile ein-/ausblenden).

OBEN, k

Vorherigen Zug auswählen (wenn ein Zug ausgewählt ist).

UNTEN, j

Nächsten Zug auswählen (wenn ein Zug ausgewählt ist).

d

Zwischen Zug- und Dopplerwürfel-Analyse wechseln (nur Match-Navigation).

Esc

Den Zug abwählen. Wenn kein Zug ausgewählt ist, das Fenster schließen.

Eval-Fenster

Tastenkürzel

Aktion

Klick

Einen Zug auswählen/abwählen (Pfeile ein-/ausblenden).

OBEN, k

Vorherigen Zug auswählen (wenn ein Zug ausgewählt ist).

UNTEN, j

Nächsten Zug auswählen (wenn ein Zug ausgewählt ist).

Esc

Den Zug abwählen.

Match-Fenster

Tastenkürzel

Aktion

Klick

Ein Match auswählen.

Doppelklick

Im Match navigieren.

OBEN, k

Vorheriges Match auswählen.

UNTEN, j

Nächstes Match auswählen.

EINGABE

Das ausgewählte Match laden.

Entf

Das ausgewählte Match löschen.

Esc

Abwählen/Fenster schließen.

Anki-Fenster (verteiltes Wiederholen)

Tastenkürzel

Aktion

LEERTASTE, Klick

Die Antwort anzeigen (die gespeicherte Analyse der Position).

1

Bewerten: Nochmal (nicht gewusst, bald wiederholen).

2

Bewerten: Schwer.

3

Bewerten: Gut.

4

Bewerten: Einfach.

p

Pip-Count ein-/ausblenden (wie das allgemeine Tastenkürzel, während der Wiederholung verfügbar).

Esc

Die Wiederholung beenden und zur Stapelliste zurückkehren (später fortsetzbar).

Turnier-Fenster

Tastenkürzel

Aktion

Klick, Doppelklick

Ein Turnier auswählen (Details anzeigen).

OBEN, k

Vorheriges Turnier auswählen.

UNTEN, j

Nächstes Turnier auswählen.

Doppelklick (auf ein Match des Turniers)

Im Match navigieren.

Esc

Die laufende Bearbeitung abbrechen, sonst die Suche zum Hinzufügen eines Matches leeren, sonst die Turnierauswahl aufheben, sonst das Fenster schließen (schrittweise).

Sammlungs-Fenster

Tastenkürzel

Aktion

Klick

Die aktuelle Stellung zur überfahrenen Sammlung hinzufügen/daraus entfernen.

Doppelklick

Die Sammlung öffnen.

Entf

Die aktuelle Stellung (oder die angehakten Stellungen) aus der geöffneten Sammlung entfernen.

Esc

Zur Liste der Sammlungen zurückkehren, sonst die Sammlungsauswahl aufheben, sonst das Fenster schließen (schrittweise).

Hilfe-Fenster

Tastenkürzel

Aktion

LINKS, h

Vorheriger Reiter.

RECHTS, l

Nächster Reiter.

OBEN, k

Nach oben scrollen.

UNTEN, j

Nach unten scrollen.

LEERTASTE

Nächste Seite.

Bild-auf

Anfang des Inhalts.

Bild-ab

Ende des Inhalts.

?, STRG-F, Esc

Hilfe schließen.
