Загрузка и установка

blunderDB — это единственный исполняемый файл, не требующий установки.

Последняя версия blunderDB доступна по лицензии MIT:

  • для Windows: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-windows-0.36.0.exe

    При первом запуске Windows показывает предупреждение SmartScreen («Система Windows защитила ваш компьютер»). Это ожидаемо: исполняемый файл не подписан цифровой подписью. См. что нужно делать.

  • для Linux: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-0.36.0

  • для Mac: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-macos-0.36.0.zip

    macOS выдаёт похожее предупреждение по той же причине: см. что нужно делать.

Для работы в режиме офлайн вы также можете скачать данную документацию в формате PDF: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-0.36.0-fr.pdf

Примечание

blunderDB использует Webview2 для отображения графического интерфейса. Вполне вероятно, что Webview2 уже установлен в вашей операционной системе. Если нет, при первом запуске blunderDB предложит скачать и установить его. Никаких действий со стороны пользователя не потребуется.

Примечание

Также при первом запуске blunderDB вычисляет в фоне две таблицы выбрасывания, которыми пользуется панель Eval: около шести секунд на одном ядре, ничего не спрашивая, и всё это время приложением можно пользоваться как обычно. См. вкладку Bearoff в настройках.

Какой файл выбрать?

Каждая версия, опубликованная на странице релизов, сопровождается тремя десятками файлов. Таблица ниже показывает, какой из них брать для вашей системы; замените x.y.z на номер версии.

Windows

blunderDB-windows-x.y.z.exe

Запустить напрямую, без установки

macOS (Intel и Apple Silicon)

blunderDB-macos-x.y.z.zip

Распаковать и перетащить blunderDB.app в Программы

Fedora, openSUSE

blunderdb-x.y.z.x86_64.rpm

sudo dnf install ./blunderdb-x.y.z.x86_64.rpm

Arch Linux, Manjaro

пакет AUR blunderdb-bin

Любой дистрибутив Linux, с Flatpak

blunderDB-x.y.z.flatpak

Linux на 64-битном ARM

blunderdb_x.y.z_arm64.deb, blunderdb-x.y.z.aarch64.rpm или blunderDB-linux-arm64-webkit2gtk-4.1-x.y.z.tar.gz

Как выше, но с файлом arm64/aarch64

Сервер (режим serve, Docker)

образ ghcr.io/kevung/blunderdb-serve

docker pull ghcr.io/kevung/blunderdb-serve:x.y.z

Файлы amd64 и x86_64 предназначены для процессоров Intel или AMD, то есть почти для всех настольных компьютеров. Файлы arm64 и aarch64 — для 64-битного процессора ARM: Raspberry Pi 4 и 5, Mac на чипе Apple под Linux, серверы ARM. Если сомневаетесь, uname -m даст ответ: x86_64 или aarch64. Пакет AUR blunderdb-bin покрывает обе архитектуры и выбирает сам.

Остальные файлы на странице — это «сырые» бинарные файлы для Linux (см. ниже), манифесты winget и Homebrew (см. Манифесты winget и Homebrew), документация в PDF на девяти языках и контрольные суммы .sha256.

Проверка загрузки

Обе описанные здесь проверки необязательны и предназначены для продвинутых пользователей: они выполняются в командной строке и не входят в установку. Пропустить этот раздел можно без каких-либо последствий.

Каждый опубликованный файл сопровождается своей контрольной суммой SHA-256 в файле с тем же именем и расширением .sha256. Загрузите оба в одну папку и убедитесь, что полученный файл — именно тот, что был опубликован:

sha256sum -c blunderdb_x.y.z_amd64.deb.sha256        # Linux
shasum -a 256 -c blunderDB-macos-x.y.z.zip.sha256   # macOS

Get-FileHash .\blunderDB-windows-x.y.z.exe -Algorithm SHA256   # Windows

В Linux и macOS команда выводит OK; в Windows сравните показанное значение с содержимым файла .sha256. Эта проверка — та гарантия, что доступна при отсутствии подписи кода (см. Приложение Windows: что делать, если Windows блокирует запуск и Приложение Mac: возможная блокировка blunderDB).

Каждый опубликованный файл также сопровождается аттестацией происхождения (SLSA, через Sigstore), которая подтверждает, что он был действительно собран официальным процессом сборки репозитория на GitHub, без необходимости управления каким-либо ключом:

gh attestation verify blunderdb_x.y.z_amd64.deb --repo kevung/blunderDB

Установка в Linux

Для Linux предлагается несколько форматов. Приведённые ниже пакеты и архивы делают blunderDB исполняемым автоматически: в отличие от необработанного двоичного файла, загруженного через браузер, они избавляют от необходимости выполнять chmod +x при каждой загрузке или обновлении. Они также создают пункт в меню приложений.

Примечание

Пакеты .deb и .rpm связывают расширение .dbx (база, экспортированная с паролем, см. Распространение базы: происхождение и пароль) с blunderDB: двойной щелчок по полученному от кого-то файлу .dbx открывает его напрямую. Расширение .db обычной базы намеренно не связывается — оно слишком общее и используется другими программами — но такой файл по-прежнему открывается обычным образом через меню Открыть blunderDB.

Нативные пакеты (.deb / .rpm)

Рекомендуемый способ в Debian, Ubuntu и Linux Mint (.deb), а также в Fedora и openSUSE (.rpm). Менеджер пакетов автоматически устанавливает подходящую зависимость webkit2gtk. Замените x.y.z на загруженную версию:

sudo apt install ./blunderdb_x.y.z_amd64.deb     # Debian / Ubuntu / Mint
sudo dnf install ./blunderdb-x.y.z.x86_64.rpm    # Fedora / openSUSE

Arch Linux (AUR)

Пакет blunderdb-bin доступен в AUR и автоматически обновляется помощниками AUR:

yay -S blunderdb-bin      # ou : paru -S blunderdb-bin

Flatpak

Пакет blunderDB-x.y.z.flatpak работает в любом дистрибутиве, где установлен Flatpak. Он опирается на среду GNOME 47, которую Flatpak загружает с Flathub, если её нет:

flatpak install ./blunderDB-x.y.z.flatpak
flatpak run io.github.kevung.blunderDB

Пакет устанавливается из загруженного файла и обновляется установкой пакета следующей версии. Приложение имеет доступ к домашней папке для открытия и сохранения баз. Командная строка (Интерфейс командной строки (CLI)) доступна через flatpak run io.github.kevung.blunderDB <команда>.

Архив .tar.gz

Для других дистрибутивов. При извлечении архива сохраняется бит исполнения, поэтому chmod не требуется:

tar xzf blunderDB-linux-webkit2gtk-4.1-x.y.z.tar.gz
cd blunderDB-linux-webkit2gtk-4.1-x.y.z
./blunderDB

Примечание

Исполняемый файл в архиве называется blunderDB, с заглавными буквами. Пакеты .deb, .rpm, AUR и Flatpak дополнительно устанавливают ссылку blunderdb в нижнем регистре — имя, которое использует документация командной строки (Интерфейс командной строки (CLI)); архив содержит ту же ссылку рядом с исполняемым файлом. Чтобы она была в вашем PATH: ln -s "$PWD/blunderDB" ~/.local/bin/blunderdb.

Необработанный двоичный файл (продвинутый способ)

Необработанный двоичный файл https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-0.36.0 остаётся доступным. Поскольку браузер удаляет бит исполнения при загрузке, его необходимо восстановить перед первым запуском:

chmod +x ./blunderDB-linux-x.y.z

Примечание

Публикуются два варианта Linux в зависимости от версии библиотеки webkit2gtk. Если вы получаете ошибку libwebkit2gtk-4.0.so.37: cannot open shared object file, ваш дистрибутив использует webkit2gtk-4.1: используйте пакет .deb/.rpm, пакет AUR или загрузите специальную сборку https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-webkit2gtk-4.1-0.36.0. Нативные пакеты выбирают правильную зависимость автоматически.

Образ Docker (серверный режим)

Серверному режиму (Безголовый режим (сервер)) настольное приложение не нужно: каждая версия публикует образ ghcr.io/kevung/blunderdb-serve в реестре GitHub для linux/amd64 и linux/arm64, с тегом версии и с тегом latest:

docker pull ghcr.io/kevung/blunderdb-serve:x.y.z

Запуск, настройка и предупреждение об аутентифицирующем прокси описаны в Публикуемый образ.

Манифесты winget и Homebrew

Каждый релиз предоставляет на странице релизов манифест winget (blunderDB-winget-manifests-x.y.z.zip) и формулу Homebrew (blunderdb-x.y.z.rb) для тех, кто хочет установить blunderDB этими менеджерами пакетов из локального файла. Ни один из них не размещён в публичных репозиториях winget или Homebrew. Ни один из них не меняет природу исполняемого файла: он остаётся неподписанным, и описанные ниже предупреждения применяются как есть.

Предупреждения для Windows и Mac

Предупреждение

В Windows система может проявлять нежелание запускать blunderDB. Смотрите Приложение Windows: что делать, если Windows блокирует запуск для понимания причин и обхода возможных блокировок.

Предупреждение

На Mac система может проявлять нежелание запускать blunderDB. Смотрите Приложение Mac: возможная блокировка blunderDB для понимания причин и обхода возможных блокировок.
