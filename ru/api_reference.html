Контракт API

Это приложение генерируется из исходного кода (go run ./cmd/openapi-gen; полный контракт со схемами см. в openapi.yaml в корне репозитория): не редактируйте его напрямую, следующая генерация перезапишет любые изменения. Каждое семейство группирует методы POST /v1/<семейство>.<метод>, предоставляемые демоном (см. Безголовый режим (сервер)), с их формой ответа (JSON или NDJSON для потокового списка) и, если применимо, упоминанием необязательного заголовка Idempotency-Key.

Идемпотентность

Большинству методов вообще не требуется никакого особого механизма: чтение не имеет побочных эффектов, а positions.save (как и остальные positions.*) естественно идемпотентен благодаря хешу содержимого Zobrist — сохранение одной и той же позиции дважды возвращает ту же строку, никогда не дубликат. 3 метода не обладают этим свойством (два вызова — это два разных эффекта) и принимают необязательный заголовок Idempotency-Key: повторный вызов с тем же ключом возвращает результат первой попытки вместо повторения эффекта — см. пометку «(Idempotency-Key)» в таблице выше. Ни один другой метод не требует и не принимает этот заголовок.
