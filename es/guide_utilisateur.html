2. Guía del usuario

Esta guía es una introducción práctica a blunderDB para un manejo rápido. Cuatro tutoriales de principio a fin cubren los usos más habituales; el resto de la guía sigue siendo un catálogo de referencia, gesto a gesto, para consultar cuando sea necesario.

2.1. Tutoriales de principio a fin

2.1.1. Mi primer import

Este tutorial parte de un archivo de partida de eXtreme Gammon (.xg) y llega hasta la lista de posiciones donde más ha perdido.

  1. Crear una base. Botón «Nueva base de datos» de la barra de herramientas (o CTRL-N), elegir una ubicación y un nombre; la extensión .db se añade automáticamente.

  2. Importar la partida. Arrastrar y soltar el archivo .xg sobre la ventana de blunderDB (o CTRL-I, y luego seleccionarlo). blunderDB detecta el formato, importa las posiciones y el análisis ya presente en el archivo XG (jugadas, decisiones de cubo, marcas), y muestra el panel de partidas cuando la importación tiene éxito.

  3. Revisar la partida. Al hacer doble clic en la fila de la partida (o seleccionarla y pulsar INTRO) se abre la revisión en la última posición visitada. Las teclas IZQUIERDA/DERECHA (o j/k) recorren las jugadas; AvPág/RePág cambian de juego.

  4. Leer el análisis. CTRL-L muestra el panel Análisis: las mejores jugadas, su equidad y el error de la jugada realizada (resaltada en la tabla). En una decisión de cubo, la misma tecla muestra la tabla de equidades de cubo y el veredicto.

  5. Encontrar los mayores errores. Desde cualquier lugar, el comando bl (o blunders, ESPACIO para abrir la línea de comandos) carga directamente en el panel de análisis las posiciones donde el error ha sido más costoso — sin necesidad de construir una búsqueda a mano para un primer repaso de una importación. Ver Panel Stats para afinar esta elección por jugador o por rango de fechas una vez importadas varias partidas.

2.1.2. Estudiar una partida

Una vez importadas varias partidas, este tutorial detalla el estudio de una partida en particular — más allá del simple recorrido del tutorial anterior.

  1. Abrir el panel de partidas (CTRL-Tab). Enumera todas las partidas importadas, ordenables por columna (jugador, fecha, longitud, torneo, PR).

  2. Abrir la revisión haciendo doble clic en la fila, o seleccionándola y pulsando INTRO. La barra de información encima del tablero recuerda a ambos jugadores, el torneo y el marcador.

  3. Alternar jugada de fichas / decisión de cubo con la tecla d sobre una misma posición cuando ambos análisis están disponibles (uno de los dos puede faltar según lo que contuviera el archivo importado).

  4. Anotar lo que observa: CTRL-P abre el panel Comentarios sobre la posición mostrada — útil para anotar por qué una jugada es un blunder, no solo que lo es.

  5. Etiquetar una posición para volver a jugarla más tarde: ESPACIO para abrir la línea de comandos, # seguido de una palabra clave (por ejemplo #blitz), INTRO. Ver Editar una posición para editar directamente la posición si la jugada realizada no es la que quiere estudiar.

  6. Salir del modo partida con el comando m: la biblioteca recupera su estado anterior, la última posición visitada de la partida se recuerda para la próxima visita.

2.1.3. Una sesión Anki

El panel Anki transforma una colección o una búsqueda en un mazo de tarjetas para repasar según el algoritmo FSRS (repetición espaciada).

  1. Constituir el mazo. Dos puntos de partida posibles: una colección de posiciones elegidas a mano, o una búsqueda (CTRL-F) — por ejemplo todas las decisiones de cubo marcadas como errores. El comando bl 30 (30 peores errores) ofrece un punto de partida idóneo para un primer mazo.

  2. Crear el mazo. Abrir el panel Anki (CTRL-K), botón «New Deck», nombrar el mazo; se sincroniza con la búsqueda o la colección elegida.

  3. Repasar (Study): cada tarjeta muestra una posición, usted formula su respuesta mentalmente, revela la solución (el tablero, el análisis y el comentario si lo hay), y luego califica su estimación de 1 (fallada) a 4 (fácil). FSRS espacia la próxima presentación en consecuencia. Nada obliga a revelar la respuesta para continuar si está seguro de sí mismo.

  4. Calentar sin perturbar el calendario (Cram): presenta posiciones aleatorias del mazo sin tocar la planificación de FSRS — práctico antes de un torneo, o para repasar intensamente sin desplazar los vencimientos de las demás tarjetas.

Ver Panel Anki para el detalle de los parámetros (limitar la sesión, tasa de retención objetivo, reiniciar un mazo).

2.1.4. Desplegar el modo servidor detrás de un proxy

El modo servidor (blunderdb serve) expone el motor de blunderDB en HTTP + JSON. No autentica a nadie (ADR-0005): confía en la cabecera X-Tenant-ID tal como la recibe, y por tanto debe colocarse siempre detrás de un proxy inverso que, él sí, autentique y fije esa cabecera. Este tutorial despliega la imagen publicada detrás de un nginx mínimo, con autenticación HTTP Basic de un solo tenant — el punto de partida más simple, a adaptar (SSO, certificados de cliente, mapeo multiusuario por usuario) según su contexto.

  1. Iniciar el demonio, restringido a 127.0.0.1 (nunca expuesto directamente):

    docker run --rm -p 127.0.0.1:8080:8080 -v blunderdb-data:/data \
    -e BLUNDERDB_BACKEND=sqlite -e BLUNDERDB_DSN=/data/blunderdb.db \
    ghcr.io/kevung/blunderdb-serve:0.35.0

  2. Crear un archivo de contraseñas para la autenticación Basic:

    htpasswd -c /etc/nginx/blunderdb.htpasswd alice

  3. Configurar nginx para autenticar y luego retransmitir, fijando X-Tenant-ID él mismo — nunca el enviado por el cliente:

    server {
    listen 443 ssl;
    server_name blunderdb.exemple.org;

    location /v1/ {
        auth_basic           "blunderDB";
        auth_basic_user_file /etc/nginx/blunderdb.htpasswd;

        proxy_pass         http://127.0.0.1:8080;
        proxy_set_header   X-Tenant-ID "1";
    }
}

  4. Verificar con el subcomando de salud, que no pasa por el proxy:

    docker exec <container> blunderdb healthcheck

Ver Modo headless (servidor) para la superficie completa (rutas, backend PostgreSQL multiusuario con Row-Level Security, migración desde SQLite) y la imagen Docker publicada.

2.2. Cómo progresar con blunderDB

Más allá de los tutoriales anteriores, una sencilla rutina semanal saca el máximo partido de blunderDB para progresar:

  1. Importar las partidas de la semana (arrastrar y soltar, o importación recursiva de carpeta si hay varios archivos) tan pronto como sea posible tras haberlas jugado — la memoria del contexto se desvanece rápido.

  2. Filtrar las decisiones más costosas: comando bl (peores errores), o el panel Stats filtrado por el período y el tipo de decisión (fichas / cubo) que más pesa en el PR.

  3. Comentar cada posición revisada: lo que se pasó por alto, la estructura en cuestión. Un comentario escrito obliga a una explicación — una posición simplemente revisada sin una palabra se olvida tan rápido como se pasó por alto.

  4. Constituir un mazo Anki a partir de estas posiciones comentadas: la repetición espaciada hace volver los mismos motivos hasta que se conviertan en reflejos.

  5. Seguir el PR por torneo en la pestaña Progresión del panel Stats (Panel Stats): una curva que baja torneo tras torneo es la única señal que nunca miente.

Esta rutina solo vale la pena si se mantiene — diez minutos por semana, sostenidos, valen más que una puesta al día puntual y luego abandonada.

2.3. Escenario de demostración (3 minutos)

Para presentar blunderDB sin una base de datos personal, el comando demo carga una base de ejemplo (posiciones y partidas ficticias). El siguiente escenario se desarrolla en tres minutos:

  1. 0:00 — demo en la línea de comandos (o el botón correspondiente de la barra de herramientas) carga la base de ejemplo. Se muestra el panel de partidas.

  2. 0:30 — Abrir una partida (doble clic), recorrer algunas jugadas con las flechas, mostrar el panel Análisis (CTRL-L) en una jugada realizada con un error visible.

  3. 1:30 — Comando bl: la vista pasa directamente a los peores errores de la base, en todas las posiciones.

  4. 2:15 — Panel Anki (CTRL-K): crear un mazo a partir de estas posiciones, lanzar una tarjeta en Study para mostrar el ciclo pregunta/respuesta/calificación.

  5. 2:45 — Vuelta al panel Stats (CTRL-D), pestaña Dashboard, para mostrar dónde se refleja este trabajo con el tiempo.

2.4. Crear una nueva base de datos

Para crear una nueva base de datos, haga clic en la barra de herramientas en el botón «Nueva base de datos». Elija una ruta donde guardar la base de datos y un nombre, y haga clic en «Save».

Nota

La extensión de las bases de datos de blunderDB es .db.

Truco

Atajos de teclado: CTRL-N. Comando: n

2.5. Abrir una base de datos existente

Para cargar una base de datos existente, haga clic en la barra de herramientas en el botón «Abrir una base de datos». Vaya a la ruta donde se encuentra la base de datos, elija el archivo .db y haga clic en «Open».

Truco

Atajos de teclado: CTRL-O. Comando: o

2.6. Importar y fusionar una base de datos

Para importar y fusionar otra base de datos blunderDB en la base actualmente abierta, haga clic en la barra de herramientas en el botón «Importar una base de datos». Elija el archivo .db que desea importar y haga clic en «Open».

blunderDB fusionará de forma inteligente las dos bases de datos:

  • Las posiciones que no existen en la base de datos actual se añadirán con sus análisis y comentarios.

  • Las posiciones que ya existen se actualizarán: los análisis se completarán si faltan, y los comentarios se fusionarán (se añadirán los nuevos comentarios sin duplicar los existentes).

  • Un mensaje resumirá el número de posiciones añadidas, fusionadas e ignoradas.

Nota

La importación requiere que ambas bases de datos tengan versiones de esquema compatibles. Es posible importar una base de datos de una versión inferior o igual en una base de datos de versión superior.

Prudencia

La operación de importación modifica inmediatamente la base de datos actualmente abierta. Se recomienda hacer una copia de seguridad antes de importar otra base de datos.

2.7. Editar una posición

Para editar una posición, pulse la tecla TAB para abrir el panel de búsqueda y el editor de posiciones. Edite la posición con el ratón:

  • haga clic en los puntos para añadir fichas. El clic izquierdo asigna las fichas al jugador 1. El clic derecho asigna las fichas al jugador 2. Para insertar una prima, haga clic en el punto de inicio, mantenga pulsado el botón y suelte en el punto de destino. Haga clic en la barra para colocar fichas en la barra.

  • para borrar la posición, haga doble clic en una zona vacía fuera del tablero o pulse la tecla RETROCESO.

  • para enviar el cubo al jugador 1, haga clic izquierdo en el cubo. Para enviar el cubo al jugador 2, haga clic derecho en el cubo.

  • para indicar el jugador que tiene el turno, haga clic en la zona reservada para los dados.

  • para editar los dados, haga clic izquierdo para aumentar el valor de un dado, clic derecho para disminuir el valor de un dado. Si las caras de los dados están vacías, significa que la posición es una decisión de cubo.

  • para editar el marcador de los jugadores, haga clic izquierdo para aumentar el marcador, clic derecho para reducirlo.

Truco

La introducción de la posición con el ratón para las fichas se realiza de la misma manera que en XG.

2.8. Añadir una posición a la base de datos

Tras editar la posición, el panel de búsqueda queda abierto.

Para guardar la posición obtenida anteriormente, pulse CTRL-S o haga clic en el botón «Save Position» de la barra de herramientas.

Truco

Abra la línea de comandos y ejecute: w

2.9. Etiquetar una posición

Para añadir una etiqueta toto a la posición actual, abra la línea de comandos pulsando ESPACIO, escriba #toto y confirme el comando pulsando INTRO.

2.10. Eliminar una posición

Para eliminar la posición actual de la base de datos, pulse Del o haga clic en el botón «Delete Position» de la barra de herramientas.

Truco

En la línea de comandos, ejecute d.

Prudencia

La eliminación de la posición es definitiva y no requiere ninguna confirmación por parte del usuario.

2.11. Importar una posición desde XG

Para importar una posición directamente desde XG,

  1. muestre en XG la posición que desea importar y pulse CTRL-C,

  2. abra blunderDB y pulse CTRL-V.

Nota

El pegado automático detecta el formato de origen (XG, GNUbg, BGBlitz).

2.12. Importar una partida

blunderDB puede importar partidas desde diversas fuentes.

Formatos compatibles:

  • eXtreme Gammon (XG): archivos .xg y .xgp (posiciones)

  • GNUbg: archivos .sgf

  • Jellyfish: archivos .mat y .txt

  • BGBlitz: archivos .bgf y .txt

Para importar uno o varios archivos de partida:

  1. Pulse CTRL-I o haga clic en el botón «Import» de la barra de herramientas.

  2. Seleccione uno o varios archivos para importar.

  3. blunderDB detecta automáticamente el formato e importa la partida.

  4. Una ventana de progreso muestra el número de archivos importados, fallidos e ignorados (duplicados).

Truco

Comando: i

Nota

blunderDB detecta automáticamente los duplicados e impide importar una partida que ya está presente en la base de datos.

2.13. Importar una carpeta de partidas

Para importar de forma recursiva todos los archivos de partidas contenidos en una carpeta y sus subcarpetas:

  1. Pulse CTRL-SHIFT-F o haga clic en el botón correspondiente de la barra de herramientas.

  2. Seleccione la carpeta que contiene los archivos de partidas.

  3. blunderDB recopila e importa automáticamente todos los archivos reconocidos (.xg, .xgp, .sgf, .mat, .txt, .bgf).

2.14. Arrastrar y soltar

blunderDB admite arrastrar y soltar. Es posible arrastrar y soltar sobre la ventana de blunderDB:

  • archivos de partida o de posición (.xg, .xgp, .sgf, .mat, .txt, .bgf) para importarlos,

  • archivos de base de datos (.db) para abrirlos o fusionarlos con la base de datos actual,

  • carpetas para importar de forma recursiva todos los archivos que contienen.

2.15. Navegar por una partida

Para navegar por una partida importada:

  1. Abra el panel de partidas con CTRL-Tab.

  2. Haga doble clic en una partida o pulse INTRO.

  3. Use las teclas IZQUIERDA / DERECHA para recorrer las jugadas.

  4. Use PageUp / PageDown para pasar de una partida a otra.

  5. Pulse CTRL-L para mostrar el análisis.

  6. Pulse d para alternar entre el análisis de jugadas de fichas y el análisis de cubo.

Truco

Atajo: CTRL-Tab para abrir el panel de partidas. Comando: m

Nota

blunderDB recuerda la última posición visitada en cada partida. Al volver a una partida, la última posición consultada se restaura automáticamente.

2.16. Gestionar el panel de partidas

El panel de partidas (CTRL-Tab) permite:

  • listar todas las partidas importadas (ordenadas de la más reciente a la más antigua),

  • ordenar las partidas por columnas (jugador 1, jugador 2, fecha, longitud de la partida, torneo),

  • modificar los nombres de los jugadores o la fecha haciendo doble clic en los campos,

  • intercambiar los jugadores 1 y 2 mediante el botón de intercambio,

  • asignar una partida a un torneo,

  • eliminar una partida con la tecla Del.

2.17. Gestionar las colecciones

Las colecciones permiten organizar posiciones en grupos personalizados. Para acceder al panel de colecciones, pulse CTRL-B.

Crear una colección:

  1. Abra el panel de colecciones (CTRL-B).

  2. Introduzca el nombre de la nueva colección y haga clic en «Add».

Añadir posiciones a una colección:

  1. Seleccione las posiciones deseadas.

  2. Añádalas a la colección desde el panel de colecciones.

Recorrer una colección:

  • Haga doble clic en una colección para recorrer sus posiciones. El orden de las colecciones y de las posiciones se puede modificar arrastrando y soltando.

Truco

Comando: coll

2.18. Gestionar los torneos

Los torneos permiten organizar las partidas importadas por evento. Para acceder al panel de torneos, pulse CTRL-Y.

Crear un torneo:

  1. Abra el panel de torneos (CTRL-Y).

  2. Haga clic en «Add» e introduzca el nombre del torneo.

Asignar una partida a un torneo:

  • Desde el panel de partidas (CTRL-Tab), use el menú desplegable de la columna de torneo para asignar una partida.

2.19. Mostrar las estadísticas de rendimiento

El panel Stats permite visualizar los indicadores de rendimiento (PR y coste MWC) a partir de las posiciones importadas.

  1. Pulse CTRL-D o haga clic en la pestaña Stats del panel inferior.

  2. Use la barra de filtros para restringir el análisis por jugador, torneo, rango de fechas, tipo de decisión o longitud de la partida.

  3. Haga clic en un indicador para acceder directamente a las posiciones correspondientes.

2.20. Evaluar una posición (panel Eval)

El panel Eval evalúa cualquier posición — no solo una carrera. En una posición de bearoff puro, calcula el EPC (Effective Pip Count) y las demás estadísticas de bearoff; en cualquier otra posición, el evaluador integrado gammonNet ofrece las jugadas candidatas o la decisión de cubo, sin conexión, sin XG ni GNUbg.

  1. Pulsar CTRL-E, hacer clic en la pestaña Eval del panel inferior, o ejecutar el comando epc: el panel se abre con un tablero vacío, listo para editar.

  2. Para evaluar la posición ya mostrada (una posición de la biblioteca, o la de una partida en curso de revisión) en lugar de un tablero vacío, clic derecho sobre el tablero y luego «Evaluate this position» — la posición mostrada se envía tal cual al panel Eval.

  3. Todo el tablero se edita con el clic o el teclado: fichas, dados, marcador, posición del cubo, jugador en turno. Editar solo las fichas del jan (últimos 6 puntos) en ambos lados coloca la posición en régimen de bearoff.

  4. Los resultados se muestran en tiempo real: en bearoff puro, EPC, número medio de tiradas, desviación estándar, pip count y wastage, la probabilidad de ganar del jugador en turno y, en el dominio exacto, el veredicto de cubo en dinero; en cualquier otra posición con dados puestos, las jugadas candidatas clasificadas por equidad; sin dados, la decisión de cubo. Ver la sección «Metodología e hipótesis del panel Eval» del manual.

  5. Para entrenarse a estimar estos valores, marque la casilla Desafío: los resultados se ocultan con cada modificación y se revelan zona por zona, con un clic.

Nota

El panel funciona para ambos jugadores simultáneamente.

2.21. Mostrar el análisis de una posición importada desde XG

Si una posición analizada por XG, GNUbg o BGBlitz se ha importado en blunderDB, el análisis se puede mostrar pulsando CTRL-L.

Si la posición corresponde a una decisión de fichas, las cinco mejores jugadas se muestran en líneas distintas. Para cada línea, la información proporcionada es, en este orden: la jugada de fichas asociada, la equidad normalizada, el error en equidad de la jugada, las probabilidades de victoria, gammon y backgammon del jugador, las probabilidades de victoria, gammon y backgammon del adversario, y el nivel de análisis.

Si la posición corresponde a una decisión de cubo, se muestra el coste de cada decisión, así como las probabilidades de victoria de la posición.

Cuando hay varios motores de análisis presentes para la misma posición (por ejemplo XG y GNUbg), una columna adicional indica el motor de origen de cada análisis.

Al navegar por una partida, la jugada realmente realizada se resalta en la lista de jugadas. Si la posición se ha encontrado en varias partidas, se indican todas las jugadas realizadas.

Truco

Al hacer clic en una jugada en el panel de análisis, las flechas correspondientes se muestran en el tablero.

2.22. Exportar una posición a XG

Para exportar una posición de blunderDB a XG,

  1. muestre en blunderDB la posición que desea exportar y pulse CTRL-C,

  2. abra XG y pulse CTRL-V.

2.23. Visualizar las distintas posiciones

Para visualizar las distintas posiciones de la biblioteca actual, use las teclas IZQUIERDA y DERECHA. La tecla INICIO permite ir a la primera posición. La tecla FIN permite ir a la última posición.

Para mostrar el bearoff a la izquierda, pulse CTRL-IZQUIERDA. Para mostrar el bearoff a la derecha, pulse CTRL-DERECHA.

2.24. Buscar posiciones según criterios

Para buscar tipos de posiciones,

  • pulse TAB para abrir el panel de búsqueda,

  • edite la estructura de posición que desea buscar. blunderDB filtrará las posiciones que tengan como mínimo la estructura de fichas introducida. En caso de duda, para obtener el máximo de resultados, borre la posición pulsando la tecla RETROCESO. Edite, si es necesario, la posición del cubo y el marcador.

El panel de búsqueda ofrece dos estructuras de fichas, seleccionables mediante las pestañas At least y Except situadas en la parte superior del panel:

  • At least (por defecto): blunderDB filtra las posiciones que tengan como mínimo la estructura de fichas introducida;

  • Except: blunderDB excluye las posiciones que contienen una de las fichas introducidas. El tablero se muestra bordeado de rojo al editar esta estructura. Una posición se rechaza si contiene al menos uno de los elementos dibujados (por ejemplo, dibujar una ficha en los puntos 1, 3 y 5 conserva únicamente las posiciones que no tienen ninguna ficha en esos puntos). El número de fichas por punto no está limitado: indicar 3 fichas en un punto excluye las posiciones que tienen 3 fichas o más en ese lugar (útil para buscar un punto hecho sin spare). Dos clics rápidos en un punto lo marcan como obligatoriamente vacío (celda roja rayada, ninguna ficha sea cual sea el color); un solo clic en ese punto lo desbloquea.

Cuando un punto pertenece a ambas estructuras, el criterio Except prevalece si contradice el criterio At least.

Método 1 (sencillo):

  • Abra la ventana de búsqueda (CTRL-F)

  • Añada y configure los filtros de búsqueda

  • Confirme haciendo clic en «Search».

Método 2 (avanzado):

  • abra la línea de comandos pulsando ESPACIO,

  • escriba s y añada los filtros adicionales que desee (por ejemplo cube o score para tener en cuenta el cubo y el marcador, respectivamente. Consulte Sección 4.4 para ver una lista exhaustiva de los filtros disponibles).

  • confirme la consulta pulsando INTRO.

Las posiciones mostradas son las de la base de datos que cumplen los criterios de búsqueda introducidos por el usuario.

2.25. Para ir más lejos

Esta guía cubre los usos más habituales. blunderDB ofrece varias funciones adicionales, detalladas en el manual:

  • Repetición espaciada (Anki) — el panel Anki (CTRL-K) convierte una colección o una búsqueda en un mazo de tarjetas para repasar según el algoritmo FSRS, con un modo de práctica libre (cram) que no altera el calendario. Véase Panel Anki.

  • Vistas múltiples — una barra de pestañas bajo la barra de herramientas permite mantener varios espacios de trabajo independientes abiertos en paralelo (por ejemplo una búsqueda y la navegación por una partida), cada uno con su propia lista de posiciones y su propio contexto. Véase Pestañas de vistas.

  • Difusión con filigrana — una exportación puede firmarse con su identidad de emisor (filigrana infalsificable que indica el origen del archivo) y protegerse con contraseña para su transporte. Véase Distribuir una base de datos: origen y contraseña.

  • Visitas guiadas y base de demostración — el comando tour (alias tutorial) abre un catálogo de visitas guiadas por la interfaz, y el comando demo carga una base de ejemplo para descubrir la herramienta sin una base propia. Véase Visitas guiadas y base de ejemplo.

  • Cargar los peores errores — el comando bl (o blunders) carga directamente los peores errores (equidad o MWC) en la vista de análisis, según el filtro actual del panel Estadísticas, sin pasar por una búsqueda manual. Véase Panel Stats.
