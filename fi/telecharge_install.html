Lataaminen ja asentaminen

blunderDB on yksittäinen suoritettava tiedosto, joka ei vaadi asennusta.

Uusin blunderDB-versio on saatavilla MIT-lisenssillä:

  • Windowsille: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-windows-0.36.0.exe

    Ensimmäisellä käynnistyskerralla Windows näyttää SmartScreen-varoituksen (”Windows suojasi tietokoneesi”). Tämä on odotettua: suoritettavaa tiedostoa ei ole allekirjoitettu digitaalisesti. Katso mitä tehdä.

  • Linuxille: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-0.36.0

  • Macille: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-macos-0.36.0.zip

    macOS näyttää vastaavan varoituksen samasta syystä: katso mitä tehdä.

Voit myös ladata tämän dokumentaation PDF-muodossa offline-käyttöä varten: https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-0.36.0-fi.pdf

Muista

blunderDB käyttää Webview2:ta graafisen käyttöliittymän piirtämiseen. On todennäköistä, että Webview2 on jo valmiiksi asennettuna käyttöjärjestelmässäsi. Jos näin ei ole, blunderDB:n ensimmäinen suorituskerta tarjoaa sen lataamista ja asentamista. Käyttäjältä ei odoteta mitään toimenpiteitä.

Muista

Niin ikään ensimmäisellä käynnistyskerralla blunderDB laskee taustalla ne kaksi bearoff-taulukkoa, joita Eval-paneeli käyttää: noin kuusi sekuntia yhdellä ytimellä, mitään kysymättä, ja sovellusta voi käyttää normaalisti sillä aikaa. Katso asetusten Bearoff-välilehti.

Minkä tiedoston valitsen?

Jokaisen julkaisusivulla julkaistun version mukana on kolmisenkymmentä tiedostoa. Alla oleva taulukko kertoo, mikä niistä sopii järjestelmällesi; korvaa x.y.z versionumerolla.

Asennus

Kuten yllä, arm64/aarch64-tiedostolla

Palvelin (serve-tila, Docker)

levykuva ghcr.io/kevung/blunderdb-serve

docker pull ghcr.io/kevung/blunderdb-serve:x.y.z

Tiedostot amd64 ja x86_64 ovat Intel- tai AMD-suorittimelle, eli lähes kaikille pöytäkoneille. Tiedostot arm64 ja aarch64 ovat 64-bittiselle ARM-suorittimelle: Raspberry Pi 4 ja 5, Applen piirillä varustetut Macit Linuxilla, ARM-palvelimet. Epäselvässä tapauksessa uname -m vastaa: x86_64 tai aarch64. AUR-paketti blunderdb-bin kattaa molemmat ja valitsee itse.

Sivun muut tiedostot ovat paketoimattomat Linux-binäärit (ks. alempana), winget- ja Homebrew-manifestit (ks. winget- ja Homebrew-manifestit), dokumentaatio PDF-muodossa yhdeksällä kielellä sekä .sha256-tarkistesummat.

Latauksen tarkistaminen

Tässä kuvatut kaksi tarkistusta ovat valinnaisia ja tarkoitettu edistyneille käyttäjille: ne tehdään komentoriviltä eivätkä ne kuulu asennukseen. Tämän osion ohittaminen ei estä mitään.

Jokaisen julkaistun tiedoston mukana on sen SHA-256-tarkistesumma samannimisessä tiedostossa, jonka pääte on .sha256. Lataa molemmat samaan kansioon ja tarkista, että saamasi tiedosto on juuri se, joka julkaistiin:

sha256sum -c blunderdb_x.y.z_amd64.deb.sha256        # Linux
shasum -a 256 -c blunderDB-macos-x.y.z.zip.sha256   # macOS

Get-FileHash .\blunderDB-windows-x.y.z.exe -Algorithm SHA256   # Windows

Linuxissa ja macOS:ssä komento tulostaa OK; Windowsissa vertaa näytettyä arvoa .sha256-tiedoston sisältöön. Tämä tarkistus on se tae, joka on käytettävissä koodiallekirjoituksen puuttuessa (ks. Windows-liite: mitä tehdä, jos Windows estää käynnistyksen ja Mac-liite: blunderDB:n mahdollinen esto).

Jokaisen julkaistun tiedoston mukana on myös alkuperätodistus (SLSA, Sigstoren kautta), joka osoittaa, että se on todella tuotettu repositorion virallisessa GitHub-koontiajossa, ilman avainten hallintaa:

gh attestation verify blunderdb_x.y.z_amd64.deb --repo kevung/blunderDB

Asentaminen Linuxiin

Linuxille tarjotaan useita muotoja. Alla olevat paketit ja arkistot tekevät blunderDB:stä automaattisesti suoritettavan: toisin kuin selaimella ladattu raaka binääri, ne välttävät komennon chmod +x suorittamisen jokaisen latauksen tai päivityksen yhteydessä. Ne luovat myös merkinnän sovellusvalikkoon.

Muista

.deb- ja .rpm-paketit liittävät .dbx-päätteen (salasanalla viety tietokanta, ks. Tietokannan jakaminen: alkuperä ja salasana) blunderDB:hen: toiselta saadun .dbx-tiedoston kaksoisnapsautus avaa sen suoraan. Tavallisen tietokannan .db-päätettä ei liitetä tarkoituksella — se on liian yleinen ja jaettu muiden ohjelmien kanssa — mutta tiedosto avautuu edelleen normaalisti blunderDB:n Avaa-valikosta.

Natiivipaketit (.deb / .rpm)

Suositeltu menetelmä Debianissa, Ubuntussa ja Linux Mintissä (.deb) sekä Fedorassa ja openSUSEssa (.rpm). Paketinhallinta asentaa automaattisesti sopivan webkit2gtk-riippuvuuden. Korvaa x.y.z ladatulla versiolla:

sudo apt install ./blunderdb_x.y.z_amd64.deb     # Debian / Ubuntu / Mint
sudo dnf install ./blunderdb-x.y.z.x86_64.rpm    # Fedora / openSUSE

Arch Linux (AUR)

Paketti blunderdb-bin on saatavilla AUR:sta, ja AUR-apuohjelmat päivittävät sen automaattisesti:

yay -S blunderdb-bin      # ou : paru -S blunderdb-bin

Flatpak

Paketti blunderDB-x.y.z.flatpak toimii missä tahansa jakelussa, johon Flatpak on asennettu. Se perustuu GNOME 47 -ajoympäristöön, jonka Flatpak lataa Flathubista, jos se puuttuu:

flatpak install ./blunderDB-x.y.z.flatpak
flatpak run io.github.kevung.blunderDB

Paketti asennetaan ladatusta tiedostosta ja päivitetään asentamalla seuraavan version paketti. Sovelluksella on pääsy kotikansioon tietokantojen avaamista ja tallentamista varten. Komentorivi (Komentoriviliittymä (CLI)) on käytettävissä komennolla flatpak run io.github.kevung.blunderDB <komento>.

.tar.gz-arkisto

Muille jakeluille. Arkiston purkaminen säilyttää suoritusbitin, joten chmod ei ole tarpeen:

tar xzf blunderDB-linux-webkit2gtk-4.1-x.y.z.tar.gz
cd blunderDB-linux-webkit2gtk-4.1-x.y.z
./blunderDB

Muista

Arkiston suoritettavan tiedoston nimi on blunderDB, isoilla kirjaimilla. Paketit .deb, .rpm, AUR ja Flatpak asentavat lisäksi pienikirjaimisen linkin blunderdb, jota komentorivin dokumentaatio (Komentoriviliittymä (CLI)) käyttää; arkisto sisältää saman linkin suoritettavan tiedoston vieressä. Saat sen PATH-polkuusi komennolla ln -s "$PWD/blunderDB" ~/.local/bin/blunderdb.

Raaka binääri (edistynyt menetelmä)

Raaka binääri https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-0.36.0 on edelleen saatavilla. Koska selain poistaa suoritusbitin latauksen yhteydessä, se on palautettava ennen ensimmäistä suoritusta:

chmod +x ./blunderDB-linux-x.y.z

Muista

Julkaistaan kaksi Linux-versiota webkit2gtk-kirjaston version mukaan. Jos saat virheen libwebkit2gtk-4.0.so.37: cannot open shared object file, jakelusi käyttää webkit2gtk-4.1:tä: käytä .deb/.rpm-pakettia, AUR-pakettia tai lataa erillinen versio https://github.com/kevung/blunderDB/releases/latest/download/blunderDB-linux-webkit2gtk-4.1-0.36.0. Natiivipaketit valitsevat oikean riippuvuuden automaattisesti.

Docker-levykuva (palvelintila)

Palvelintila (Headless-tila (palvelin)) ei tarvitse työpöytäsovellusta: jokainen versio julkaisee levykuvan ghcr.io/kevung/blunderdb-serve GitHubin rekisteriin alustoille linux/amd64 ja linux/arm64, sekä versiotunnisteella että tunnisteella latest:

docker pull ghcr.io/kevung/blunderdb-serve:x.y.z

Käynnistys, määritys ja varoitus todentavasta välityspalvelimesta on kuvattu kohdassa Julkaistu kuva.

winget- ja Homebrew-manifestit

Jokainen julkaisu tarjoaa julkaisusivulla winget-manifestin (blunderDB-winget-manifests-x.y.z.zip) ja Homebrew-kaavan (blunderdb-x.y.z.rb) niille, jotka haluavat asentaa blunderDB:n näillä paketinhallinnoilla paikallisesta tiedostosta. Kumpikaan ei ole wingetin tai Homebrew’n julkisissa arkistoissa. Kumpikaan ei muuta suoritettavan tiedoston luonnetta: se pysyy allekirjoittamattomana, ja alla kuvatut varoitukset pätevät sellaisinaan.

Windows- ja Mac-varoitukset

Varoitus

Windowsissa se saattaa epäröidä blunderDB:n suorittamista. Katso Windows-liite: mitä tehdä, jos Windows estää käynnistyksen ymmärtääksesi miksi ja ohittaaksesi mahdolliset estot.

Varoitus

Macissa se saattaa epäröidä blunderDB:n suorittamista. Katso Mac-liite: blunderDB:n mahdollinen esto ymmärtääksesi miksi ja ohittaaksesi mahdolliset estot.
