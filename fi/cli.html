Komentoriviliittymä (CLI)

Johdanto

blunderDB sisältää täydellisen komentoriviliittymän (CLI) samassa suoritettavassa tiedostossa kuin graafinen käyttöliittymä. CLI on erityisen hyödyllinen seuraaviin tarkoituksiin:

  • ottelujen massatuonti: koko hakemistollinen ottelutiedostoja (XG, SGF, MAT, BGF…) tuodaan yhdellä komennolla,

  • automaatio: blunderDB:n integrointi shell-skripteihin säännöllisiä varmuuskopioita, ajastettuja vientejä tai käsittelyputkia varten,

  • palvelinkäyttö: tietokantojen hallinta koneilla, joilla ei ole graafista ympäristöä,

  • nopea tarkastus: tietokannan sisällön tai eheyden tarkistaminen käynnistämättä graafista käyttöliittymää.

CLI käyttää täsmälleen samaa tietokantamuotoa kuin graafinen käyttöliittymä: molemmat kirjoittavat samaa tiedostoa, eikä mitään tarvitse synkronoida.

Muista

Jos sovellus on auki samalla kun skripti kirjoittaa. Tiedosto on WAL-tilassa: luku ei koskaan estä kirjoitusta, ja molemmat ohjelmat työskentelevät samassa tietokannassa toisiaan häiritsemättä. Kaksi kirjoitusta sen sijaan seuraavat toisiaan — jälkimmäinen odottaa kirjoituslukkoa (kymmenen sekuntia lausetta kohti ja muutama uudelleenyritys päälle) eikä epäonnistu ennen kuin odotusaika on kulunut umpeen, jolloin viesti mainitsee SQLiten:

Error: failed to import match: sqlite: save match: database is locked (5) (SQLITE_BUSY)

Graafinen käyttöliittymä ei tarkkaile tiedostoa: se näyttää edelleen sitä, minkä oli ladannut, kunnes CTRL-R lataa asemat uudelleen. Mitään ei menetetä, mutta näyttö on tietokantaa jäljessä.

Yleinen syntaksi

Tila tunnistetaan automaattisesti: jos ensimmäinen argumentti on CLI-komento, blunderDB käynnistyy headless-tilassa, muuten se käynnistää graafisen käyttöliittymän.

# GUI
./blunderdb

# CLI
./blunderdb <command> [options]

Tämän sivun esimerkeissä kirjoitetaan ./blunderdb: binääri sellaisena kuin se ladataan, kutsuttuna siitä kansiosta, jossa se sijaitsee. Paketista asennettuna tai PATH-kansiosta linkitettynä (katso Lataaminen ja asentaminen) se on yksinkertaisesti blunderdb.

Totuusarvoiset valitsimet, joiden kohdalla lukee ”oletus: kyllä”, poistetaan käytöstä muodolla --option=false — --recursive=false, --analysis=false. Välilyönnillä erotettua muotoa ei ole: --recursive false jättää valitsimen oletusarvoonsa ja käsittelee sanaa false yhtenä argumenttina liikaa.

Käytettävissä olevat komennot

Komento

Kuvaus

create

Luo uusi tietokanta.

import

Tuo tietoja (ottelu, asema, erä).

export

Vie tietoja.

transfer

Kopioi osan kirjastosta toiseen ilman välitiedostoa.

identity

Näyttää tai siirtää liikkeeseenlaskijan identiteetin (vesileimojen allekirjoitusavain).

open

Muuntaa salasanalla suojatun tiedoston (.dbx) tavalliseksi tietokannaksi.

search

Hae asemia suodattimilla.

list

Näytä tietokannan sisältö.

match

Näytä ottelun asemat ja analyysit.

transcribe

Toistaa litteroinnin ja raportoi, mitä toisto löytää.

duel

Pelaa kaksintaistelua yksi toiminto kutsua kohden (luonti, siirto, kuutio, luovutus, lopetus).

collection

Hallitsee kokoelmia (luettelo, sisältö, luonti, uudelleennimeäminen, poisto, vienti).

study

Opiskelujono: pelaajan, johon verrataan, käsittelemättömät blunderit sekä merkintä ”nähty”.

lesson

Hallitsee oppitunteja (järjestetyt vaiheet, jotka näyttävät kokoelmia ja asemia) ja vie ne.

anki

Välitoistopakat (luettelo, tilastot, ennuste, synkronointi).

stats

Tilastot, jotka lasketaan erikseen komennosta list --type stats (toistuvat virheet, sijoitus, raportti…).

training

Harjoittelupäiväkirja (istunnot, ohitetut asemat).

comment

Lukee ja lisää aseman kommentit, jotka on liitetty kirjoittajaansa.

elsewhere

Mitä muut tietokannat tietävät asemasta, ja sen naapurit niissä.

cubematrix

Aseman kuutiotuomio ottelun jokaisessa pistetilanteessa.

rollout

Pelaa aseman loppuun asti erottaakseen sen siirrot tai tuplauspäätöksen toisistaan (XGID tai OGID).

epc

Laskee ulosajoaseman (XGID tai OGID) Effective Pip Countin ja kuutiotuomion.

gnubgid

Kirjoittaa asemalle GNU Backgammonin antaman aseman tunnuksen ja ottelun tunnuksen (XGID tai OGID).

capture

Lukee aseman, jonka eXtreme Gammon -laudan kuvakaappaus näyttää.

openingbook

Avaussiirto tai pelin vastaus tiettyyn pistetilanteeseen, poimittu upotetusta avauskirjasta ja arvioitu sitä vasten.

bearoff

Luo, listaa, tarkistaa ja poistaa bearoff-tietokantoja.

analyze

Kirjoittaa gammonNet-analyysin jokaiselle asemalle, jolla ei ole yhtään analyysiä.

tournament

Lukee johdetun turnauksen (sijoitukset, kaaviot, sivut) ja vahvistaa sen ehdotukset.

players

Pelaajan kirjoitusasut (aliakset), pelaajien yhdistäminen ja vaihtaminen keskenään.

events

Tapahtuman kirjoitusasut (aliakset).

trash

Roskakori: luettelo, palautus, peruutettavissa oleva poisto.

info

Näytä tietokannan metatiedot.

edit

Muokkaa tietokannan metatietoja ja kynnysarvoja.

verify

Tarkista tietokannan eheys.

vacuum

Tiivistää tietokantatiedoston ja ottaa vapautuneen tilan takaisin.

met

Luettelee ja tuo tietokannan ottelun ekviteettitaulukon ja valitsee sen.

reencode

Kirjoittaa analyysit uudelleen tiiviiseen muotoon.

repair

Laskee uudelleen sen, minkä tietokanta johtaa siitä mitä se tallentaa.

maintenance

Tietokannan terveydentila: laskurit, toiminnot ja viimeisimmät ajot.

delete

Poista tietoja.

healthcheck

Kysyy käynnissä olevalta serve-taustaprosessilta: paluukoodi 0, jos se on valmis.

mcp

Tarjoaa tietokannan työkalut tekoälyavustajalle (Model Context Protocol).

completion

Tulostaa shell-täydennysskriptin (bash, zsh, fish).

help

Näytä ohje.

version

Näytä versio.

serve, migrate, call

Palvelintila ja siirto PostgreSQL:ään: ks. Headless-tila (palvelin).

Työnkulkuesimerkkejä

Turnaushakemiston tuonti

./blunderdb create --db tournoi_paris.db --user "Jean" --description "Open de Paris 2025"
./blunderdb import --db tournoi_paris.db --type batch --dir ./matchs_open_paris/
./blunderdb list --db tournoi_paris.db --type stats

Säännöllinen varmuuskopiointi

./blunderdb export --db production.db --type database --file sauvegarde-$(date +%Y%m%d).db

Virheiden analysointi

# Les positions délicates, puis celles de videau
./blunderdb search --db production.db --error-min 0.1 --export blunders.db
./blunderdb search --db production.db --decision cube --error-min 0.05 --export cube_errors.db

# Les coups réellement fautifs : au moins 100 millièmes d'équité perdus
./blunderdb search --db production.db --move-error-min 100 --format json

Paluukoodit

  • 0 — Onnistui.

  • 1 — Virhe.

Tämä tekee CLI:stä sopivan käytettäväksi skripteissä virheenkäsittelyn kanssa:

if ./blunderdb import --db base.db --type match --file match.xg; then
    echo "OK"
else
    echo "KO"
    exit 1
fi
