API-sopimus

Tämä liite luodaan lähdekoodista (go run ./cmd/openapi-gen; katso openapi.yaml repositorion juuressa täydellistä sopimusta varten, kaaviot mukaan lukien): älä muokkaa sitä suoraan, seuraava luonti korvaisi kaikki muutokset. Jokainen perhe kokoaa palvelimen tarjoamat POST /v1/<perhe>.<metodi> -metodit (ks. Headless-tila (palvelin)), niiden vastausmuodon kanssa (JSON tai NDJSON suoratoistetulle listalle) ja, jos se on olemassa, maininnan valinnaisesta Idempotency-Key-otsakkeesta.

Idempotenssi

Useimmat metodit eivät tarvitse mitään erityistä mekanismia: luvuilla ei ole sivuvaikutuksia, ja positions.save (kuten muutkin positions.*) on luonnostaan idempotentti Zobrist-sisältötiivisteensä ansiosta — saman position tallentaminen kahdesti palauttaa saman rivin, ei koskaan kaksoiskappaletta. 3 metodilta puuttuu tämä ominaisuus (kaksi kutsua ovat kaksi erillistä vaikutusta), ja ne hyväksyvät valinnaisen Idempotency-Key-otsakkeen: samalla avaimella uudelleen yritetty kutsu palauttaa ensimmäisen yrityksen tuloksen sen sijaan, että toistaisi vaikutuksensa — ks. merkintä «(Idempotency-Key)» yllä olevassa taulukossa. Mikään muu metodi ei tarvitse tai hyväksy tätä otsaketta.
