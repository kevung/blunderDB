# Réponses de la bibliographie

Coller ici chaque réponse de claude.ai, un fichier par prompt, même numéro et même nom que dans
`../prompts/` : `01-webviews-acces-images.md`, `02-etat-de-l-art-des-et-plateau.md`, …

En tête de chaque fichier, deux lignes : la date de la recherche et l'outil (claude.ai, recherche
approfondie). Le reste est la réponse telle quelle ; la synthèse se fait dans `../synthese.md`, pas
en retouchant les réponses.
