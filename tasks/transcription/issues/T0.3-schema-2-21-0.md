# T0.3 — Table `transcription`, 2.21.0 dans les trois copies, `demo.db`, étape d'export [M]

Le brouillon (T0.2) a besoin d'une ligne à écrire après chaque geste ; sans elle rien ne
survit à un plantage (ADR-0045 §1). La table est neuve, la version de schéma doit donc
avancer dans les deux backends et dans la copie GUI/CLI, comme toute migration
(CLAUDE.md, « Schema changes »).

**Tranche verticale** : Go (schéma desktop + storage) → export → démo régénérée → tests.
Pas de binding Wails ni de Svelte à ce stade (T1.1 les ajoute).
**Prérequis** : T0.1 (vocabulaire du document).
**Livrable** : une base ouverte à 2.20.0 migre vers 2.21.0 sans perte ; la table
`transcription` existe, vide, dans une base neuve des deux backends ; l'export complet la
copie, l'export filtré ne la copie pas.
