# T1.10 - Documentation [M]

Le lot 1 livre un panneau, un mode, des raccourcis et une commande entièrement utilisables
(T1.1-T1.9) mais aucune ligne de documentation ne les décrit encore ; « une fonctionnalité
visible ne ferme pas son lot sans sa documentation » (CLAUDE.md).

**Tranche verticale** : documentation seule (pas de code applicatif), mais verticale sur ses
propres neuf langues : source française -> huit `.po` -> vérification -> bundles d'aide
intégrée régénérés.
**Prérequis** : T1.9
**Livrable** : `blunderdb` documente le panneau Transcription dans le manuel, ses touches
dans les raccourcis, sa commande dans le mode commande, en français et dans les huit
traductions, et l'aide intégrée (`?`) les reflète.

## Travail
- `doc/source/manuel.rst` : section « Transcription » - le panneau, la création, la saisie,
  la correction, l'enregistrement, l'export, le brouillon. Description d'écran, pas de
  parcours pas à pas (règle CLAUDE.md : « le guide montre une tâche, le manuel décrit un
  écran » - le parcours complet, s'il est jugé nécessaire, irait dans le guide utilisateur,
  hors périmètre de cette fiche).
- `doc/source/raccourcis.rst` : `Ctrl+Maj+T` et le tableau des touches du panneau (`1`-`6`,
  `j`/`k`, `h`/`l`, `i`/`a`/`x`/`s`, `d`/`t`/`p`/`r`, Entrée, Retour arrière, `Ctrl+Z`/
  `Ctrl+Maj+Z`) - `keyboardShortcuts.sync.test.js` l'exige.
- `doc/source/cmd_mode.rst` : `transcribe`/`tr` - `commandVocabulary.sync.test.js` et
  `helpVocabulary.sync.test.js` l'exigent.
- `scripts/doc-po-update.sh` puis `scripts/doc-i18n-check.sh` sur les huit catalogues (`de`,
  `el`, `en`, `es`, `fi`, `it`, `ja`, `ru`, `frontend/src/i18n/locales/*.json` déjà couvert
  par T1.1-T1.9) - jamais `sphinx-build`/`sphinx-intl` à la main (chemin gettext relatif).
- `make help` puis `go test ./cmd/help-gen` : les bundles `frontend/src/i18n/help/*.js`
  régénérés, jamais édités à la main (ADR-0034).
- Prix estimé (intégration.md §5) : manuel ≈ 45 msgid x 8, raccourcis ≈ 18 msgid x 8,
  cmd_mode ≈ 3 msgid x 8, soit ≈ 66 msgid x 8 langues pour cette fiche (le total du lot avec
  la CLI du lot 3 et l'annexe de schéma monte à ≈ 75 msgid x 8 ≈ 600 lignes de catalogue).

## Recette
- `scripts/doc-i18n-check.sh` se termine sur « all translations complete ».
- `go test ./cmd/help-gen` vert.
- Aucune occurrence de « à venir », « en préparation », « pas encore publié », « prévu »,
  « une fois publié » dans les sections ajoutées (règle de factualité, CLAUDE.md).
- Relecture croisée : la section manuel ne duplique aucun parcours déjà décrit dans un guide
  existant (pas de contenu en double entre guide et manuel).

## Invariants touchés
- « Une fonctionnalité visible s'accompagne de sa documentation », même branche que le code
  (CLAUDE.md, Development Workflow).
- L'aide intégrée est générée depuis ces mêmes sources (ADR-0034) : jamais l'inverse.
- Le prix d'une page se dit avant de l'écrire (CLAUDE.md, Documentation) : ici une section,
  pas une page nouvelle.
