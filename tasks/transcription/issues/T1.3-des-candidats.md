# T1.3 - Dés, candidats [M]

Une fois l'ouverture jouée (T1.2), rien ne permet encore de saisir un tour de pions : ni les
dés, ni la liste des coups légaux classés, ni leur validation. C'est le geste le plus
fréquent du document (fonctionnel.md §1.2, ~250 fois par match) et le cœur du budget KLM.

**Tranche verticale** : Go (`transcript.Apply` pour `checker`/`dance`, wiring) -> binding ->
Svelte (machine à états du clavier, réutilisation de `CandidateMovesTable.svelte`) -> tests
(vitest + Go de latence).
**Prérequis** : T1.2
**Livrable** : au tour d'un camp, deux chiffres affichent les coups légaux classés en 0-ply,
premier présélectionné ; `j`/`k` change la sélection, un chiffre depuis « candidat choisi »
valide et relance le jet suivant, Entrée valide seule ; un jet sans coup légal crée
directement une danse.

## Travail
- `internal/gui/legal_moves.go:24` (`LegalMoves`) et `internal/gui/gammonnet_eval.go:99`
  (`EvaluatePositionImmediate`, 0-ply) réutilisés tels quels sur la position du Cursor et ses
  dés, exactement comme `EPCPanel` les utilise déjà - aucun changement Go dans ces fichiers.
- `internal/gui/transcription.go` : `ApplyTranscriptionGesture` gagne les gestes `roll`,
  `select`, `validate`, `dance`, délégués à `transcript.Apply` (T0.2).
- `frontend/src/components/TranscriptionPanel.svelte` : machine à états du clavier (ux.md
  §3) - dés attendus / un dé / jet corrigeable / candidat choisi ; monte
  `frontend/src/components/CandidateMovesTable.svelte` avec `baseline={null}
  showProvenance={false}` (même usage qu'`EPCPanel`, cf. le commentaire d'ADR-0018 en tête du
  composant).
- `frontend/src/stores/transcriptionStore.js` : état de la machine à touches, index de
  sélection du candidat.
- Plateau : flèches du candidat sélectionné via `selectedMoveStore` (`analysisStore.js`),
  déjà branché sur `Board.svelte` - pas de changement du composant.
- Touches gérées localement au panneau (pas dans `keyboardService.js` global) : `1`-`6`,
  `j`/`k`, Retour arrière, Entrée ; `frontend/src/services/keyboardService.js`'s
  `panelKeyGuard` decide ce que le panneau laisse remonter (Ctrl-combos, Espace, `?`).
- `frontend/src/i18n/locales/*.json` : libellé « aucun coup » (danse).
