# T1.2 - Création, ouverture [S]

L'onglet de T1.1 est vide : rien n'y crée un document, rien n'y joue la première Action.
Sans création ni ouverture, aucun geste de saisie n'a de document sur lequel s'exercer.

**Tranche verticale** : Go (`CreateTranscription` construit le document via `transcript`,
`ApplyTranscriptionGesture` gère la première Action `opening`) -> binding -> Svelte
(formulaire de création, saisie des deux dés d'ouverture) -> tests.
**Prérequis** : T1.1
**Livrable** : « nouvelle transcription » demande la longueur (et Jacoby/beaver si argent) et
ouvre un plateau initial score `[N, N]` en attente d'une `opening` ; saisir deux dés dérive le
gagnant du trait ou, à égalité, relance.

## Travail
- `pkg/blunderdb/database/db_transcription.go` : `CreateTranscription(header)` pose
  `match_length`/`jacoby`/`beaver` par défaut (fonctionnel.md §1.1) et construit le document
  vide via `transcript.NewDocument` (T0.2).
- `internal/gui/transcription.go` : `CreateTranscription`/`OpenTranscription` retournent
  l'`Annotated` (Replay complet, T0.2) ; `ApplyTranscriptionGesture(id, gesture)` gagne son
  premier cas, `opening`.
- `frontend/src/components/TranscriptionPanel.svelte` : formulaire « nouvelle
  transcription » (longueur, case « partie d'argent » qui affiche Jacoby/beaver) ; état
  « ouverture » qui prend `1`-`6` puis `1`-`6` (ux.md §3, dernière ligne).
- `frontend/src/stores/transcriptionStore.js` : reçoit le document/Cursor renvoyés par
  `CreateTranscription`/`OpenTranscription`.
- `frontend/src/i18n/locales/*.json` : « nouvelle transcription », « longueur », « partie
  d'argent », « relance ».

## Recette
- ux.md 4.5 : `Ctrl+Maj+T`, « nouvelle », `7`, Entrée pour un brouillon en 7 points, budget
  ≈ 1,5 s.
- fonctionnel.md flux 1 et 2 : document vide, `opening` attendue, plateau initial, score
  `[N, N]` ; deux dés égaux -> « relance », `opening` attendue à nouveau ; sinon le gagnant a
  le trait.
- `go test ./pkg/blunderdb/database/...` : `CreateTranscription` puis
  `ApplyTranscriptionGesture` avec un jet d'ouverture produisent le document attendu (dés
  d'ouverture portés par la première Action `checker` suivante, fonctionnel.md §1.2).
- vitest : le formulaire refuse une longueur non renseignée et n'affiche Jacoby/beaver que
  si « partie d'argent » est cochée.

## Invariants touchés
- Drapeaux de session `has_jacoby`/`has_beaver` non hashés (ADR-0028) : posés sur le
  document, pas encore sur une Position tant qu'aucun Move n'existe.
- Svelte 5 : `$store` uniquement.
