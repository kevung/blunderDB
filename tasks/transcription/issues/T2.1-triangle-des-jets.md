# T2.1 — Triangle des 21 jets [S]

Saisir un jet au clavier coûte deux touches, mais une saisie tout-souris n'a aucune cible
pour les dés : la grille 6×6 classique affiche 36 cases pour 21 jets distincts (`ux.md`
§ 4.1), avec l'ambiguïté visuelle 3-1/1-3. Il faut une cible qui ne montre que les jets
possibles, une fois chacun.

**Tranche verticale** : prototype jetable → composant Svelte `DiceTriangle.svelte` → câblage
dans `TranscriptionPanel.svelte` (état « dés attendus » ou « ouverture ») → geste
`transcriptionStore` → tests unitaires du composant.
**Prérequis** : T1.3 (la liste de candidats 0-ply et le clavier des dés existent déjà).
**Livrable** : un clic sur une case du triangle produit le même effet qu'avoir tapé les deux
chiffres au clavier ; l'ouverture (deux camps) l'utilise aussi.

## Travail
- **Prototype d'abord** (skill `prototype`, obligatoire avant tout code définitif) : une page
  jetable qui pose 21 cases triangulaires dans une fenêtre à 1024 px, mesure au chronomètre
  ou à l'enregistrement d'écran le temps de pointage réel d'un clic sur une case de bord et
  une case de coin, et confirme ou corrige les tailles de cible utilisées dans les calculs de
  `ux.md` § 1 et § 4.1 (28 px, loi de Fitts, ID ≈ 3,6 bits). Le prototype est jeté ; seule sa
  conclusion (taille de case retenue) passe au composant réel.
- `frontend/src/components/DiceTriangle.svelte` : nouveau composant, 21 cases (`i ≤ j` sur
  une grille 6×6), une case = un jet, doubles sur la diagonale ; `onPick(d1, d2)`.
- Câblage dans `TranscriptionPanel.svelte` : affiché à côté du clavier des dés (maquette
  `ux.md` § 2), jamais à sa place ; le clavier reste plus rapide (0,56 s vs 1,14 s) et les
  deux coexistent.
- `transcriptionStore.js` : le geste « saisir un dé » accepte déjà une paire complète (clic)
  aussi bien qu'une touche à la fois ; pas de nouveau geste métier, seulement un nouveau
  déclencheur.
- Ouverture : les deux triangles (J1, J2) ou un seul réutilisé deux fois, selon ce que montre
  le prototype comme le moins ambigu.

## Recette
- Test du composant : cliquer la case (3,1) déclenche `onPick(3, 1)` exactement une fois,
  sans dépendre de l'ordre d'affichage des dés.
- Mesure manuelle sur le composant fini (pas seulement le prototype) : un clic sur une case
  de bord ≤ 1,14 s (H + P(28 px) + B + B, `ux.md` § 4.1) ; noté dans la PR, pas automatisé
  (Playwright ne chronomètre pas une loi de Fitts, il compte des gestes ; T3.5 vérifie le
  nombre de clics, pas leur durée).
- `blunderdb transcribe` (CLI, T3.4) n'est pas concerné : le triangle est un geste souris,
  sans équivalent CLI.

## Invariants touchés
- Svelte 5 store rule (CLAUDE.md) : `DiceTriangle.svelte` lit `transcriptionStore` en `$store`,
  jamais `.subscribe()`.
- Un type scale (CLAUDE.md) : les libellés des cases utilisent les tokens de `style.css`, pas
  un `font-size` local.
