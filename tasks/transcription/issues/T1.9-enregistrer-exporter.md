# T1.9 - Enregistrer, exporter [M]

Un match transcrit et corrigé (T1.7) reste un brouillon tant qu'il n'est ni un Match ordinaire
analysé par gammonNet, ni un fichier `.mat`. C'est le geste qui rend la transcription utile
au reste du logiciel (statistiques, Anki, recherche).

**Tranche verticale** : Go (`SaveTranscriptionAsMatch` appelle `ingest.WriteMatch` en mode
remplacement puis le lot gammonNet ciblé ; export `.mat` via un dialogue système) -> binding
-> Svelte (boutons Enregistrer/Exporter/Fermer, confirmation, avertissement) -> tests.
**Prérequis** : T1.7, T0.4 (en-têtes `.mat`), T0.5 (`WriteMatch` remplacement), T0.6 (lot
ciblé + annulation au `shutdown`)
**Livrable** : « Enregistrer » crée ou remplace le Match (même `id` au second
enregistrement), lance l'analyse ciblée, et le Match apparaît dans le panneau Match ;
« Exporter » produit un `.mat` avec avertissement si un coup illégal est présent ; « Fermer »
supprime le brouillon après confirmation s'il a déjà été enregistré.

## Travail
- `internal/gui/transcription.go` : `SaveTranscriptionAsMatch(id)` appelle
  `ingest.WriteMatch` en mode remplacement (T0.5) puis
  `AnalyzeMissingWithGammonNet` filtré sur le match
  (`pkg/blunderdb/database/db_gammonnet_batch.go:90`, T0.6) ;
  `ExportTranscriptionMAT(id, path)`/`SuggestTranscriptionMatFilename(id)` via
  `runtime.SaveFileDialog`, sur le modèle d'`internal/gui/image_export.go:50` ;
  `CloseTranscription(id)`.
- `frontend/src/services/confirmService.js` : `confirmAction()` pour « fermer le brouillon »
  si jamais enregistré, et pour l'avertissement coup illégal à l'export (fonctionnel.md §5).
- `frontend/src/components/TranscriptionPanel.svelte` : boutons « Enregistrer » (`Ctrl+S` si
  `isAlwaysGlobal`/`keyboardService.js` laisse le panneau le prendre - sinon `Ctrl+Entrée`,
  risque nommé au plan.md, à vérifier ici), « Exporter .mat », « Fermer ».
- Barre d'état : progression du lot d'analyse ciblé après enregistrement (ux.md §5), sur le
  modèle des barres de progression d'import déjà existantes.
- `frontend/src/i18n/locales/*.json` : « enregistrer », « exporter le match », « fermer le
  brouillon », message d'avertissement coup illégal.

## Recette
- ux.md 4.5 : enregistrer = `Ctrl+S` dans le panneau, 1 K.
- fonctionnel.md flux 18-20 et 22 : l'enregistrement crée/remplace le Match (même `id` au
  second enregistrement, seules les positions nouvelles analysées, ADR-0013) ; l'export
  produit `Player1_Player2_YYYY-MM-DD_Np.mat` ; la fermeture confirme si jamais enregistré,
  le Match déjà enregistré reste et devient définitif.
- `go test ./pkg/blunderdb/database/...` : un ré-enregistrement ne réanalyse que les
  positions nouvelles du match.
- Vérification manuelle : le `.mat` exporté s'importe dans gnubg sans « Invalid move » pour
  un match sans coup illégal (aller-retour `gnubgparser.ParseMAT`, T0.2/T0.4).

## Invariants touchés
- Rien n'est écrit côté destinataire ; le remplacement ne passe pas par le Trash (ADR-0045
  §3, il n'en existe d'ailleurs pas pour `Match` aujourd'hui).
- Positions identifiées par Zobrist hash : `SavePosition` via `ingest.WriteMatch`.
- `shutdown` (`internal/gui/run.go:74`) annule le lot en cours avant `Close()`.
