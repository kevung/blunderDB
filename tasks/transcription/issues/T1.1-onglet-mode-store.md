# T1.1 - Onglet, mode, store [M]

Aujourd'hui rien n'ouvre une transcription : pas d'onglet, pas de mode `TRANSCRIBE`, pas de
store. Sans point d'entrée, aucune des issues suivantes n'a d'endroit où vivre.

**Tranche verticale** : Go (`Database`, bindings minimales lister/créer/ouvrir/fermer) ->
binding Wails -> Svelte (onglet, mode, store, raccourci, commande) -> tests (Go + vitest) ->
i18n neuf langues pour le libellé de l'onglet.
**Prérequis** : T0.2 (paquet `transcript`), T0.3 (table `transcription`, 2.21.0)
**Livrable** : `Ctrl+Maj+T` (ou `transcribe`/`tr` en commande) ouvre un onglet Transcription
vide, qui affiche la liste des brouillons existants et un bouton de création ; quitter
l'onglet restaure la position étudiée avant.
