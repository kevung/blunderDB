# T1.7 - Correction, Replay [M]

Une transcription se corrige constamment (dé mal lu, coup oublié, coup en double, camp
inversé) ; sans correction en place ni annulation, la moindre erreur oblige à tout
recommencer. Le Transcript (T1.6) donne l'endroit où corriger, il manque le geste.

**Tranche verticale** : Go (`transcript.Apply`/`Replay` pour correction, insertion,
suppression, changement de camp - wiring, la logique pure est T0.2) -> binding -> Svelte
(touches `i`/`a`/`x`/`s`, `Ctrl+Z`/`Ctrl+Maj+Z`, pile undo/redo, saut à la première
Incohérence) -> tests.
**Prérequis** : T1.6
**Livrable** : reculer le Cursor puis ressaisir corrige l'Action en place et le Cursor y
revient après validation ; `i`/`a` insèrent, `x`/Suppr suppriment, `s` change le camp ;
`Ctrl+Z`/`Ctrl+Maj+Z` annulent/rétablissent ; chaque geste relance un `Replay` qui saute le
Cursor à la première Incohérence si le document en gagne une.

## Travail
- `internal/gui/transcription.go` : `ApplyTranscriptionGesture` gagne `correct`,
  `insertBefore`, `insertAfter`, `delete`, `swapSide`, `undo`, `redo`, tous délégués à
  `transcript.Apply`/`Replay` (T0.2).
- `frontend/src/components/TranscriptionPanel.svelte` : touches `i`/`a` (insertion avant/
  après, camp proposé pour rendre la suite cohérente), `x`/Suppr (suppression), `s`
  (changement de camp), `Ctrl+Z`/`Ctrl+Maj+Z` (ux.md §3).
- `frontend/src/stores/transcriptionStore.js` : pile undo/redo de documents en mémoire
  seulement (perdue au replantage, fonctionnel.md §3 - la persistance durable est T1.8).
- `frontend/src/components/TranscriptView.svelte` : après un `Replay`, scrolle et met en
  évidence la première Incohérence (fonctionnel.md §1.4).
- `frontend/src/i18n/locales/*.json` : « insérer avant/après », « supprimer », « changer de
  camp ».

## Recette
- ux.md 4.3 : candidat voisin vu aussitôt, une touche `j`/`k` = 1 K = 0,28 s (la correction
  la plus fréquente : le candidat choisi n'est pas encore validé) ; dé mal lu vu aussitôt,
  `4` `1` = 2 K = 0,56 s ; correction vue un tour plus tard, Retour + `h` + `j` + `l` = 4 K =
  1,12 s.
- fonctionnel.md flux 12-15 : correction à mi-match, insertion, suppression, changement de
  camp - chacun suivi d'un `Replay` qui remet le Cursor à sa place antérieure (sauf
  suppression, qui va à l'Action suivante).
- Test Go de latence : `Replay` sur un document de 300 Actions <= 20 ms (seuil ux.md §7,
  formalisé au lot 3 mais déjà vérifié ici en unitaire).
- vitest : `Ctrl+Z` annule la dernière Action, `Ctrl+Maj+Z` la rétablit ; une correction qui
  rend un coup suivant illégal le marque sans le supprimer.
