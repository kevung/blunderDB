# T1.6 - Transcript deux colonnes [M]

La saisie (T1.3) écrit des Actions mais rien n'en montre l'historique : sans vue du
Transcript, l'utilisateur ne peut ni relire ce qu'il a saisi, ni repérer une Incohérence, ni
situer le Cursor pour une correction (T1.7).

**Tranche verticale** : Svelte (nouveau composant deux colonnes, décorations d'Incohérence,
parties repliables, export texte copiable) -> tests (vitest, `colorTokens.sync.test.js`).
Aucun changement Go : le Replay annoté (T0.2) porte déjà tout ce qu'il faut afficher.
**Prérequis** : T1.3
**Livrable** : la moitié droite du dock (ux.md §2) montre le Transcript en deux colonnes
(J1/J2), la cellule du Cursor encadrée, les Incohérences décorées avec info-bulle, la partie
courante ouverte et les autres repliées, un volet dépliable avec le texte `.mat` exact et un
bouton « copier ».

## Travail
- `frontend/src/components/TranscriptView.svelte` (nouveau) : rendu en deux colonnes à
  partir de l'`Annotated` du document (T0.2) - conçu réutilisable par le panneau Match
  (intégration.md §4, décision différée pour ce panneau-là).
- `frontend/src/components/TranscriptionPanel.svelte` : monte `TranscriptView` à droite du
  dock (ux.md §2, ASCII-art du placement).
- `frontend/src/stores/transcriptionStore.js` : expose l'`Annotated` par partie (Position
  d'avant/après, Incohérences) nécessaire au rendu.
- Cursor : `h`/`l` (et flèches) déplacent le Cursor et chargent les dés/candidat de l'Action
  visée (ux.md §3) ; un clic sur une cellule du Transcript fait de même à la souris (ux.md
  4.3, `P B B` ≈ 1,3 s).
- `frontend/src/i18n/locales/*.json` : « copier », noms de colonnes, texte des info-bulles
  d'Incohérence (une par ligne du tableau fonctionnel.md §1.4).

## Recette

  laquelle ; partie courante ouverte, autres repliées ; en-tête de partie = score initial +

- `colorTokens.sync.test.js` vert : aucune couleur hex dans le `<style>` du nouveau
  composant.
