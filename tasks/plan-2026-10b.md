### D — J.9 devient MCP + assistant (#299)
- **Lot 1 — serveur MCP.** `pkg/blunderdb/mcp` : une vingtaine d'outils de haut niveau sur
  les handlers (recherche avec la grammaire en description, position + analyse, explication,
  stats joueur, erreurs récurrentes, rollout, quiz…). Monté en HTTP dans
  `pkg/blunderdb/server` (`/mcp`, multi-tenant, hérité par gammonGo, ADR-0005 inchangée) ;
  stdio par `blunderdb mcp` (Claude Code, Desktop) ; hébergé par la GUI sur localhost quand
  elle tourne, avec les outils d'affichage en plus (ouvrir une vue, montrer une position).
  Lecture seule par défaut, écriture derrière un drapeau. ADR. Nouvelle commande →
  `CLI_USAGE.md`, `cli.rst`.
- **Lot 2 — assistant interne**, client de ces outils. Fournisseur compatible OpenAI, Ollama
  par défaut ; préréglages Ollama, Groq, OpenRouter, Gemini, Anthropic (clé API), autre.
  Avertissement de confidentialité pour un distant ; clé dans le trousseau, jamais dans la
  base. Une phrase → **nouvelle vue** (onglets de vues, `viewStore`) nommée d'après la phrase,
  recherche lancée, bascule ; jetons visibles dans le panneau Recherche. Navigue et lit
  partout (Recherche, Stats, Analyse, Quiz, Rollout, Direction en lecture) ; toute écriture
  préparée puis confirmée. Texte libre du modèle marqué comme tel. Choix du modèle recommandé
  par une mesure livrée (corpus de phrases dans les 9 langues).
